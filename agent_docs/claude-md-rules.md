- **60줄 이하 유지** — 매 세션마다 로드되므로 짧을수록 좋음

## 포함해야 하는 것 (WHAT / WHY / HOW)

- **WHAT**: 기술 스택, 프로젝트 구조, 디렉토리 맵
- **WHY**: 아키텍처 규칙과 그 이유
- **HOW**: 빌드/테스트 명령어, path alias, 작업 방법

## 포함하지 않는 것

- 코드 스타일 규칙 (ESLint + TS strict이 처리)
- 상세 API 문서 (코드 자체가 문서)
- 특정 작업에만 해당하는 지시 (보편적 지시만)
- 코드 스니펫 예시
- Phase 2+ 미래 계획
