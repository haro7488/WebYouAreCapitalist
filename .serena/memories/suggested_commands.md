# Suggested Commands

## Development
- `npm run dev` — Start development server (Vite)
- `npm run build` — TypeScript check + production build (**run after every task**)
- `npm run lint` — Run ESLint
- `npm run preview` — Preview production build

## Git (Windows)
- `git status` — Check working tree
- `git add <files>` — Stage changes
- `git commit -m "메시지"` — Commit (Korean messages, no Co-Authored-By)
- `git log --oneline -10` — Recent commits
- `git diff` — View changes

## System (Windows)
- `dir` or `ls` — List files (PowerShell)
- `type <file>` or `cat <file>` — Read file (PowerShell)
- `findstr /s /i "pattern" *.ts` — Search in files
- `mkdir <dir>` — Create directory

## Notes
- Node 20.11.0 (create-vite@8+ needs Node >=22, use @6)
- Always run `npm run build` after completing work to verify no type errors
