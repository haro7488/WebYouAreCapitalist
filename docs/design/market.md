# 시장 & 경제 시스템 상세 기획

> 글로벌 시장 사이클, 7섹터 트렌드, 인플레이션, 정부 연동의 복합 경제 시스템.

---

## 디자인 철학

### 다층 변동: 읽을 수 있지만 통제할 수 없는 경제

시장 시스템은 네 개의 독립적 레이어로 구성된다:

1. **글로벌 시장** (boom/stable/recession) — 전체 경제 분위기
2. **섹터 트렌드** (hot/neutral/cold) — 7개 섹터 각각 독립
3. **인플레이션** — 복리로 누적, 가격과 소득 동시 상승
4. **정부 이벤트** — 매 턴 1개, 시장 상태에 직접 개입

이 구조가 만드는 플레이어 경험:
- **완전한 랜덤이 아님**: 전환 확률 매트릭스 + 정보 기업을 통한 조사로 예측 가능
- **완전한 통제도 아님**: 정부가 매 턴 시장에 개입하여 예측을 뒤집을 수 있음
- **인플레이션 압박**: 가만히 있으면 뒤처진다 — 성장이 필수

핵심 감정: **"대충 읽히지만, 정부가 뭘 할지는 모르겠다"**

## 글로벌 시장 사이클

### 3가지 상태

| 상태 | 소득 배율 | 변동성 범위 | 핵심 영향 |
|------|----------|-----------|----------|
| **boom** (호황) | ×1.3 | 0.2~0.5 | 대부분 자산 수익 증가, 낮은 변동성 |
| **stable** (보합) | ×1.0 | 0.3~0.7 | 기본 상태, 중간 변동성 |
| **recession** (불황) | ×0.7 | 0.5~0.9 | 수익 감소, 높은 변동성, 이벤트 빈발 |

### 유지 기간

시장 상태는 **4~8턴** 동안 유지된 후 전환된다. RNG로 결정되며, 정보 기업의 조사로 남은 턴 수를 확인 가능.

### 전환 확률 매트릭스

| 현재 \ 다음 | boom | stable | recession |
|-------------|------|--------|-----------|
| **boom** | 20% | 50% | 30% |
| **stable** | 30% | 40% | 30% |
| **recession** | 30% | 50% | 20% |

**설계 의도:**
- 자기 자신으로 돌아올 확률이 가장 낮음 (20~40%)
- boom→recession, recession→boom 직접 전환 가능 (30%) → 급변 리스크
- stable이 가장 자주 등장하는 "기본 상태" 역할
- 정부 이벤트에 의해 강제 전환될 수 있음 (아래 참조)

### 변동성과 이벤트

```
추가 이벤트 발생 확률 = EVENT_BASE_PROBABILITY + volatility × VOLATILITY_EVENT_BONUS
                     = 0.3 + 변동성 × 0.3
```

> 매 턴 고정 1개 이벤트 발생 + 위 확률로 추가 이벤트 발생 가능.

| 시장 | 변동성 | 추가 이벤트 확률 |
|------|--------|---------------|
| boom | 0.2~0.5 | 36~45% |
| stable | 0.3~0.7 | 39~51% |
| recession | 0.5~0.9 | 45~57% |

**설계 의도**: 불황일수록 이벤트가 더 자주 추가 발생 → 리스크 체감 증가. 호황은 상대적으로 안정.

## 섹터 트렌드

### 7개 섹터

| 섹터 | 특성 | 정보 섹터 연동 |
|------|------|--------------|
| **외식** | 안정적, 저비용 진입 | - |
| **기술** | 고수익, 고변동 | - |
| **부동산** | 불황 내성, 느린 ROI | - |
| **물류** | 중간 균형, 안정적 수익 | - |
| **에너지** | 시장 사이클 민감, 중수익 | - |
| **금융** | 극단적 시장 민감도 | - |
| **정보** | 조사 능력 제공, 시장 예측 | 보유 기업이 조사 행동 가능 |

### 3가지 트렌드

| 트렌드 | 소득 배율 | 가치 보정 | 효과 |
|--------|----------|----------|------|
| **hot** | ×1.3 | +2%/턴 추가 | 수익 증가 + 자산 가치 빠르게 상승 |
| **neutral** | ×1.0 | 기본 | 기본 상태 |
| **cold** | ×0.7 | -1%/턴 감소 | 수익 감소 + 자산 가치 하락 |

### 유지 기간

트렌드는 **2~6턴** 동안 유지. 글로벌 시장보다 짧아서 더 자주 변동.

### 전환 확률 매트릭스 (기본)

| 현재 \ 다음 | hot | neutral | cold |
|-------------|-----|---------|------|
| **hot** | 15% | 55% | 30% |
| **neutral** | 25% | 50% | 25% |
| **cold** | 30% | 55% | 15% |

### 글로벌 시장의 영향

글로벌 시장이 섹터 전환에 영향을 준다:

| 글로벌 시장 | hot 보정 | neutral 보정 | cold 보정 |
|------------|---------|-------------|---------|
| boom | +10% | -5% | -5% |
| stable | 0% | 0% | 0% |
| recession | -5% | -5% | +10% |

**설계 의도**: 글로벌 시장이 "분위기"를 잡고, 섹터가 개별적으로 반응. boom 시기에도 특정 섹터는 cold일 수 있고, recession에서도 hot 섹터가 존재할 수 있음.

## 인플레이션

### 기본 메커니즘

인플레이션은 **복리로 매 턴 누적**되며, 자산 가격과 소득에 동시에 영향을 준다.

```
인플레이션율  = max(0%, 기본율 + 정부보정)
누적 인플레이션 = (1 + 인플레이션율)^경과턴수
```

| 항목 | 공식 | 설명 |
|------|------|------|
| 자산 매입 가격 | `baseCost × 누적인플레이션` | 후반으로 갈수록 자산이 비싸짐 |
| 자산 패시브 소득 | `baseIncome × 누적인플레이션 × 기타배율` | 이미 보유한 자산의 소득도 증가 |
| 기본 지출 | `BASE_EXPENSES × 누적인플레이션` | 생활비도 물가에 연동 |
| 업그레이드 비용 | `baseCost × 0.3 × (현재레벨+1) × 누적인플레이션` | 업그레이드도 비싸짐 |

### 인플레이션율 결정

```
기본 인플레이션율 = 2%/턴
```

정부 이벤트에 의해 조정될 수 있다:

| 정부 행동 | 인플레이션 보정 | 예시 |
|----------|--------------|------|
| 금리 인상 | -1~2%p | 인플레이션 억제, 경기 냉각 |
| 양적 완화 | +1~2%p | 인플레이션 상승, 유동성 증가 |
| 긴축 재정 | -1%p | 소폭 인플레이션 억제 |
| 경기 부양 | +1%p | 소폭 인플레이션 상승 |

### 최소 0% 제한

```
적용 인플레이션율 = max(0%, 계산된_인플레이션율)
```

디플레이션(마이너스 인플레이션)은 발생하지 않는다. 정부가 아무리 긴축해도 인플레이션율은 0% 이하로 떨어지지 않음.

### 누적 효과 예시 (기본 2%/턴)

| 턴 | 누적 인플레이션 | $100 자산 가격 | $8 소득 | $15 지출 |
|----|--------------|--------------|--------|---------|
| 1 | 1.00 | $100 | $8 | $15 |
| 5 | 1.08 | $108 | $8.6 | $16.2 |
| 10 | 1.22 | $122 | $9.8 | $18.3 |
| 15 | 1.35 | $135 | $10.8 | $20.3 |
| 20 | 1.49 | $149 | $11.9 | $22.4 |
| 25 | 1.64 | $164 | $13.1 | $24.6 |
| 30 | 1.81 | $181 | $14.5 | $27.2 |

**설계 의도**:
- 소득과 가격이 함께 올라 기존 자산 보유자에게 유리 (인플레이션 헤지)
- 현금만 쥐고 있으면 구매력이 하락 → **투자 강제**
- 후반 진입 비용 증가 → 초반 투자의 중요성 강조
- 정부 이벤트와 연동하여 동적 경제 환경 조성

## 정부 시스템과 시장 연동

### 정부 이벤트

정부 이벤트는 **매 턴 고정 1개** 발생한다 (일반 이벤트와 별도). 정부 탭에서 확인 가능.

### 정부가 시장에 미치는 영향

| 정부 이벤트 유형 | 시장 영향 | 인플레이션 영향 | 빈도 |
|----------------|----------|--------------|------|
| **금리 정책** | 시장 전환 확률 보정 | ±1~2%p | 높음 |
| **재정 정책** | 특정 섹터 트렌드 보정 | ±1%p | 중간 |
| **규제 정책** | 특정 섹터 cold 강제 가능 | - | 낮음 |
| **부양 정책** | 시장 boom 전환 확률 증가 | +1%p | 중간 |

### 정부 → 시장 상호작용 흐름

```
턴 구조: 자유 행동 → [정부 이벤트] → [일반 이벤트] → 정산 → 결과
                         │                  │
                         ▼                  ▼
                    시장/인플레이션 보정    특성 부여/제거
                         │
                         ▼
                    정산에 즉시 반영
```

정부 이벤트가 먼저 처리되므로, 해당 턴의 정산에 정부 결정이 즉시 반영된다. 플레이어는 자유 행동 시점에서 이번 턴 정부가 무엇을 할지 모른 채 행동을 결정해야 한다.

### 정부 이벤트와 시장 사이클 연동

정부는 현재 시장 상태에 반응하여 행동한다:

| 현재 시장 | 정부 성향 | 가능한 행동 |
|----------|----------|-----------|
| **boom** | 과열 억제 | 금리 인상, 규제 강화 → 인플레이션↓, boom 단축 |
| **stable** | 균형 유지 | 소폭 조정 → 큰 변화 없음 |
| **recession** | 경기 부양 | 금리 인하, 재정 지출 → 인플레이션↑, recession 탈출 촉진 |

**설계 의도**: 정부가 시장의 극단을 완화하는 "자동 균형 장치" 역할. 그러나 정부 행동 자체가 새로운 불확실성을 만들어 게임을 예측 불가능하게 만든다.

## 시장 풀

### 구조

시장 풀은 각 섹터별로 유통되는 자산의 전체 현황이다.

```typescript
interface MarketPool {
  /** 섹터별 매입 가능 자산 목록 */
  available: Record<SectorId, Asset[]>;
  /** 인플레이션 반영 현재 가격 */
  currentPrices: Record<AssetId, number>;
  /** 섹터별 현재 트렌드 */
  trends: Record<SectorId, TrendState>;
  /** 글로벌 시장 상태 */
  marketState: MarketState;
  /** 현재 누적 인플레이션 */
  cumulativeInflation: number;
}
```

### 가격 결정

모든 자산의 시장 가격은 인플레이션을 반영한다:

```
현재 가격 = floor(baseCost × cumulativeInflation)
```

매각 시:

```
매각 금액 = floor(현재가치 × 매각효율)
매각효율  = BASE_SELL_RATIO + MARKET_SELL_BONUS × marketMultiplier[시장]
```

| 시장 | 매각효율 (대략) |
|------|--------------|
| boom | 0.85 + 0.15 × 높은값 ≈ 0.90~0.95 |
| stable | 0.85 + 0.15 × 1.0 = 0.89~0.92 |
| recession | 0.85 + 0.15 × 낮은값 ≈ 0.80~0.85 |

### 자산 가치 업데이트 (매 턴)

```
현재가치 = 현재가치 × (1 + appreciation + 트렌드보정) × (1 + 인플레이션율)
```

- hot 섹터: appreciation + 2%/턴
- cold 섹터: appreciation - 1%/턴
- 인플레이션이 가치 상승에 복합적으로 작용

## 조사 시스템 (정보 기업)

### 기본 규칙

AP가 삭제되었으므로 조사는 **정보 섹터 기업** 보유를 통해 수행한다.

| 규칙 | 내용 |
|------|------|
| 조사 수단 | 정보 섹터 자산 보유 |
| 조사 횟수 | 보유 정보 기업 1개당 **1회/턴** |
| 조사 대상 | 플레이어가 직접 선택 |
| 비용 | 없음 (정보 기업 보유가 비용) |

### 조사 종류

| 조사 유형 | 결과 | 정확도 |
|----------|------|--------|
| **시장 조사** | 현재 시장의 남은 턴 수 + 다음 상태 확률 분포 | 높음 (남은 턴 정확, 확률 공개) |
| **섹터 조사** | 특정 섹터의 다음 트렌드 확률 분포 | 중간 (확률 분포 공개) |
| **정부 조사** | 다음 턴 정부 이벤트 힌트 | 낮음 (카테고리만 공개) |

### 정보 기업과 조사 능력

정보회사는 1종류이며, 1개당 1회/턴 조사가 가능하다. 여러 개 보유 시 그만큼 조사 횟수가 늘어난다.

### 전략적 가치

정보 기업은 직접 소득은 낮지만, 시장 예측 능력을 제공한다:
- **시장 전환 예측** → 매입/매각 타이밍 최적화
- **섹터 트렌드 예측** → hot 섹터 선점, cold 섹터 이탈
- **정부 행동 예측** → 인플레이션 변동 대비

**설계 의도**: 정보는 "간접 수익"이다. 정보 기업 자체의 ROI는 낮지만, 올바른 투자 판단을 가능하게 해 전체 포트폴리오의 수익을 극대화한다.

## 시스템 상호작용 종합

### 자산 턴 소득 공식

```
자산 턴 소득 = floor(
  baseIncome
  × 누적인플레이션
  × marketMultiplier[시장]
  × trendMultiplier[트렌드]
  × upgradeMultiplier
  × dominanceMultiplier
  × 특성배율
)
```

| 배율 요소 | 출처 | 범위 |
|----------|------|------|
| 누적인플레이션 | 인플레이션 시스템 | 1.0~1.81 (30턴, 2%/턴) |
| marketMultiplier | 글로벌 시장 | 자산별 고유값 |
| trendMultiplier | 섹터 트렌드 | hot 1.3 / neutral 1.0 / cold 0.7 |
| upgradeMultiplier | 업그레이드 레벨 | 1.0 / 1.25 / 1.5625 / 1.953 |
| dominanceMultiplier | 지배력 등급 | 1.0 / 1.1 / 1.25 |
| 특성배율 | 이벤트 부여 특성 | 이벤트에 따라 다양 |

### 순수익 공식

```
총소득   = Σ(자산별 턴 소득)
총지출   = floor(BASE_EXPENSES × 누적인플레이션 × 이벤트지출배율)
이자비용 = 현금 < 0 ? abs(현금) × 이자율 : 0
순수익   = 총소득 - 총지출 - 이자비용 + 이벤트직접금액
잔고     = 잔고 + 순수익
```

> 파산: 현금이 마이너스가 되어도 즉시 게임오버가 아님. 매 턴 이자 페널티가 부과되며, 매각 가능 자산이 없고 소득으로 회복 불가능할 때 파산.

### 턴 처리 순서와 시장 업데이트 타이밍

```
1. 자유 행동    → 플레이어 매입/매각/업그레이드 (현금으로 무제한)
2. 정부 이벤트  → 인플레이션 보정, 시장/섹터 개입
3. 일반 이벤트  → 고정 1개 + 추가 확률, 특성 부여/제거
4. 정산        → 소득 계산, 지출 차감, 이자 부과, 가치 업데이트
   4-1. 인플레이션 적용 (누적인플레이션 갱신)
   4-2. 자산별 소득 계산 (갱신된 인플레이션 반영)
   4-3. 지출 차감 (인플레이션 반영)
   4-4. 이자 부과 (마이너스 잔고 시)
   4-5. 자산 가치 업데이트 (appreciation + 트렌드 + 인플레이션)
   4-6. 글로벌 시장 상태 전환 판정
   4-7. 섹터 트렌드 전환 판정
   4-8. 영향력 자연 감소 (-1/턴)
5. 결과        → 턴 요약 표시
```

## 플레이어 전략

### 인플레이션 대응

| 전략 | 효과 | 적합한 상황 |
|------|------|-----------|
| **조기 매입** | 낮은 가격에 자산 확보, 인플레이션 헤지 | 게임 초반 |
| **현금 최소화** | 현금은 가치가 하락 → 자산으로 전환 | 항상 |
| **정보 기업 투자** | 정부 행동 예측 → 인플레이션 변동 대비 | 중반 이후 |

### 시장 사이클 대응

| 시장 | 추천 행동 |
|------|----------|
| **boom** | 적극 매입 (특히 금융/기술), 매각은 자제 (높은 매각효율이지만 소득이 더 가치) |
| **stable** | 포트폴리오 정비, 섹터 다각화, 정보 기업으로 다음 사이클 예측 |
| **recession** | 방어적 운영, 부동산 비중 확대, cold 섹터 자산 저가 매입 기회 |

### 정보 활용 전략

| 정보 기업 수 | 전략 |
|------------|------|
| 0개 | 시장을 읽지 못함 → 분산 투자로 리스크 관리 |
| 1개 | 조사 1회/턴 → 핵심 섹터 1개의 트렌드 예측 |
| 2개 | 조사 2회/턴 → 시장 + 섹터 동시 조사 |
| 3개 (지배) | 조사 3회/턴 + 지배력 소득 보너스 → 시장을 "읽는" 플레이어 |

### 정부 대응 전략

- **금리 인상 예상 시**: boom 자산 매각 고려, 현금 비중 일시 확대
- **부양책 예상 시**: recession 저가 자산 선점, 인플레이션 상승 대비 자산 확보
- **규제 예상 시**: 해당 섹터 비중 축소, 다른 섹터로 분산
