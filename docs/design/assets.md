# 자산 시스템 상세 기획 (Phase 2)

> 7섹터 구조 (6섹터 × 3티어 + 정보 1개 = 19자산). 물류 섹터 추가, 정보 기업 1종 통합, AP 삭제(현금=행동력), 인플레이션 반영.

---

## 디자인 철학

### 7섹터 구조 (6×3 + 정보 1 = 19자산)

기존 5섹터(외식/기술/부동산/유통/금융)에서 **유통 → 에너지**로 교체, **물류·정보 섹터 신규 추가**. 정보 섹터는 티어 구분 없이 1종류.

- **Tier 1 (진입)**: $100~$200. 초반 즉시 구매 가능. 높은 ROI%.
- **Tier 2 (성장)**: $400~$600. 중반 포트폴리오 확장.
- **Tier 3 (지배)**: $1,200~$2,000. 후반 지배력 완성용.

### 현금 = 행동력

AP가 삭제되었다. **현금이 있으면 무제한 행동**. 매입/매각/업그레이드에 행동 횟수 제한 없음.

- 매 턴 자유 행동 페이즈에서 원하는 만큼 행동 가능
- 현금 부족 시 자연스럽게 행동 종료
- 지출(생활비, 이자 등)이 유일한 현금 압박 수단

### 자산 = 유일한 수입원

기본 수익 $0. 아무것도 안 사면 매턴 생활비만 나간다.

## 섹터 정체성

### 기술 (Tech) — 고위험 고수익

| 특성 | 값 |
|------|-----|
| 시장 민감도 | 극단적 (boom ×1.6~1.8, recession ×0.3~0.5) |
| ROI 범위 | 7~8% |
| Appreciation | 3~5% |
| 리스크 | high |

boom 시 최고 수익, recession 시 반토막. 높은 appreciation으로 장기 보유 매각 차익 기대.

### 식품 (Food) — 균형형, 입문자 친화

| 특성 | 값 |
|------|-----|
| 시장 민감도 | 보통 (boom ×1.2~1.4, recession ×0.7~0.85) |
| ROI 범위 | 6~8% |
| Appreciation | 1~3% |
| 리스크 | low~medium |

가장 안정적. Tier 1이 최저가($100)로 첫 매입 후보. 섹터 지배 비용도 최저.

### 부동산 (Real Estate) — 안정형, 불황 방어

| 특성 | 값 |
|------|-----|
| 시장 민감도 | 극히 낮음 (boom ×1.1~1.3, recession ×0.85~0.95) |
| ROI 범위 | 4~6% |
| Appreciation | 2~4% |
| 리스크 | low~medium |

불황에서도 5~15%만 감소하는 안전 자산. 비용이 높아 기회비용 큼.

### 물류 (Logistics) — 안정 성장형

| 특성 | 값 |
|------|-----|
| 시장 민감도 | 중간 (boom ×1.2~1.4, recession ×0.6~0.8) |
| ROI 범위 | 6~8% |
| Appreciation | 1.5~3% |
| 리스크 | medium |

물류 수요는 경기와 함께 움직이지만 극단적이지 않다. 안정적 성장과 적당한 수익의 균형.

### 에너지 (Energy) — 중간 변동, 인플레 연동

| 특성 | 값 |
|------|-----|
| 시장 민감도 | 중상 (boom ×1.3~1.5, recession ×0.5~0.7) |
| ROI 범위 | 6~8% |
| Appreciation | 1.5~3% |
| 리스크 | medium |

인플레이션 상승 시 에너지 가격도 동반 상승 → 소득이 인플레에 강한 섹터. 기존 유통 대체.

### 금융 (Finance) — 극단형, 타이밍 의존

| 특성 | 값 |
|------|-----|
| 시장 민감도 | 최극단 (boom ×1.5~2.0, recession ×0.1~0.3) |
| ROI 범위 | 7~8% |
| Appreciation | 0~2% |
| 리스크 | high |

boom 시 게임 최고 수익. recession 시 소득 사실상 0. Appreciation 최저 → 순수 소득형 자산.

### 정보 (Information) — 조사 특화, 유틸리티

| 특성 | 값 |
|------|-----|
| 시장 민감도 | 낮음 (boom ×1.1~1.2, recession ×0.8~0.9) |
| ROI 범위 | 3~5% |
| Appreciation | 1~2% |
| 리스크 | low |

**소득이 낮은 대신 조사 기능 제공.** 티어 구분 없이 '정보회사' 1종류만 존재. 1개당 1회/턴 무료 조사. 다른 섹터 트렌드·이벤트 힌트를 확인할 수 있다.

## 정보 섹터 & 조사 시스템

### 조사 메커니즘

정보회사는 소득 대신 **무료 조사 능력**을 제공한다. 티어 구분 없이 1종류.

| 규칙 | 내용 |
|------|------|
| 조사 횟수 | 보유 정보회사 1개당 **1회/턴** |
| 대상 선택 | 플레이어가 조사 대상 섹터 선택 |
| 조사 결과 | 대상 섹터의 다음 턴 트렌드 + 이벤트 힌트 |
| 비용 | **무료** |

### 조사 보너스 (매각 시)

조사로 얻은 정보를 기반으로 매각하면 보너스 적용.

```
매각금액 = floor(현재가치 × 매각효율 × 조사보너스)
조사보너스 = 1.0 + (해당 섹터 조사 횟수 × 0.05)  // placeholder
```

- 조사 1회 시 매각가 +5%
- 조사 누적 가능 (같은 섹터 반복 조사 시)

### 정보 투자 전략

정보회사는 **보조 자산**이다. 소득이 낮으므로 단독으로는 수익 부족.

```
추천 구성: 소득용 자산 4~5개 + 정보회사 1~2개
         → 무료 조사로 시장 예측 → 최적 타이밍에 매입/매각
```

## 업그레이드 시스템

### 공식

```
업그레이드 비용 = 자산원가 × 0.3 × (현재레벨 + 1)
소득 배율      = 1.25^레벨 (지수적 증가)
최대 레벨      = 3
```

### 레벨별 분석 (포장마차 $100 기준)

| 레벨 | 비용 | 누적비용 | 소득 배율 | 턴 소득 | 추가 소득 |
|------|------|---------|----------|--------|----------|
| 0 | - | $0 | ×1.00 | $8.00 | - |
| 1 | $30 | $30 | ×1.25 | $10.00 | +$2.00 |
| 2 | $60 | $90 | ×1.56 | $12.50 | +$2.50 |
| 3 | $90 | $180 | ×1.95 | $15.63 | +$3.13 |

### 인플레이션과 업그레이드 비용

인플레이션은 **업그레이드 비용에도 적용**된다.

```
실제 업그레이드 비용 = 업그레이드 비용 × (1 + 인플레이션율)^경과턴
```

후반으로 갈수록 업그레이드가 비싸짐 → 초반 업그레이드 유리.

## 매각 메커니즘

### 기본 공식

```
매각금액 = floor(현재가치 × (기본비율 + 시장비율 × 시장배율) × 조사보너스)
```

- `기본비율(SELL_BASE_RATIO)`: 0.85
- `시장비율(SELL_MARKET_RATIO)`: 0.15
- `시장배율`: 자산의 `marketMultiplier[현재시장상태]`
- `조사보너스`: 해당 섹터 조사 누적에 따라 1.0~1.x

### 시장 상태별 매각 효율 (상가 건물 $600 기준)

| 시장 | 시장배율 | 매각 효율 | 매각가 (조사 0회) | 매각가 (조사 2회) |
|------|---------|----------|-----------------|-----------------|
| boom | 1.2 | 103% | $618 | $680 |
| stable | 1.05 | ~101% | $604 | $664 |
| recession | 0.9 | 98.5% | $591 | $650 |

> 조사 2회 = 조사보너스 ×1.10 (placeholder)

## 인플레이션 영향

정부 시스템에서 매 턴 인플레이션이 복리로 적용된다.

### 영향 범위

| 대상 | 영향 | 방향 |
|------|------|------|
| 자산 매입가 | 원가 × 인플레 배율 | 상승 ↑ |
| 업그레이드 비용 | 비용 × 인플레 배율 | 상승 ↑ |
| 자산 소득 | 소득 × 인플레 배율 | 상승 ↑ |
| 매각금액 | 현재가치에 인플레 반영 | 상승 ↑ |
| 생활비 | 지출 × 인플레 배율 | 상승 ↑ |

### 인플레 공식

```
인플레 배율 = (1 + 인플레이션율)^경과턴
// 인플레이션율: 정부 정책에 의해 결정 (placeholder: 1~3%/턴)
```

### 섹터별 인플레 민감도

| 섹터 | 인플레 영향 | 이유 |
|------|-----------|------|
| 에너지 | **높음** — 소득 인플레 배율 ×1.2 | 에너지 가격이 인플레에 선행 |
| 부동산 | **높음** — appreciation에 인플레 가산 | 실물 자산 가치 보존 |
| 물류 | 보통 — 표준 인플레 적용 | 운송비 연동 |
| 식품 | 보통 — 표준 인플레 적용 | 필수 소비재 |
| 기술 | **낮음** — 소득 인플레 배율 ×0.8 | 디플레이션 성향 (효율화) |
| 금융 | 보통 — 표준 인플레 적용 | 금리와 상쇄 |
| 정보 | **낮음** — 소득 인플레 배율 ×0.8 | 디지털 재화 |
