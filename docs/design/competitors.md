# AI 경쟁사 시스템 설계

> Phase 2 핵심 기능. 매 런마다 AI 경쟁사와 함께 경쟁하는 투자 로그라이트.
> AP 삭제 후 현금 = 행동력 체제. 7섹터(정보 포함). 정부 시스템 연동.

---

## 절대 원칙

### 1. 동일 엔티티 원칙

플레이어와 경쟁사는 본질적으로 같은 `Company` 엔티티다. 게임 엔진은 누가 조종하는지 모른다. 보드게임의 오토마와 같은 구조.

### 2. 현금 = 행동력

AP 시스템은 삭제. 현금이 있는 한 무제한 행동 가능. AI도 동일한 규칙으로 현금 기반 의사결정.

```
행동 가능 조건 = company.cash > 0 (매입/업그레이드 비용 충족 시)
행동 제한 = 현금 부족 시 자연 종료
```

### 3. 화폐 보존 법칙

시스템 내 총 화폐량은 변하지 않는다. 돈은 생성되지도 소멸되지도 않으며, 참여자 간에 이동할 뿐이다.

```
총 화폐 = Σ(company.cash) + Σ(asset market value) + marketPool = 상수
```

## Company 엔티티

```typescript
interface Company {
  id: string;
  name: string;             // "한강투자", "청담캐피탈" 등
  cash: number;             // 현금 = 행동력
  assets: OwnedAsset[];
  influence: number;
  netWorth: number;          // cash + Σ(asset value)
  dominatedSectors: SectorId[];
  traits: Trait[];           // 이벤트에서 부여/제거되는 특성
  debt: number;              // 마이너스 시 누적 부채 (이자 페널티)
}

// 컨트롤러는 엔진 바깥
interface Controller {
  type: 'human' | 'ai';
  strategy?: CompetitorStrategy;  // AI일 때만
  difficulty: DifficultyLevel;     // AI 난이도
}

// 전략 패턴
interface CompetitorStrategy {
  id: string;
  name: string;
  decide(state: GameState, company: Company): Action[];
}
```

- 엔진은 `Company[]`와 `Action[]`만 처리
- UI 레이어에서만 human/ai 구분
- `ap`, `maxAp` 필드 완전 삭제

## 경쟁사 설정

| 항목 | 값 | 비고 |
|------|-----|------|
| 기본 수 | 3 | 상수로 조절 가능, 테스트 후 확정 |
| 이름 | 한국형 기업명 | 시드 RNG로 매 런 랜덤 배정 |
| 시작 자금 | 플레이어와 동일 ($1,000) | 동일 엔티티 원칙 |


## 전략 타입 (4개)

Strategy Pattern으로 교체 가능한 구조. 데이터는 JSON 선언형, 로직은 TS.

### 전략 개요

| 타입 | 행동 패턴 | 리스크 | 현금 운용 |
|------|----------|--------|----------|
| 🏦 **보수형** | Tier 1~2 분산, 불황 시 현금 비축, 안전 우선 | 낮음 | 항상 50%+ 현금 유보 |
| 🚀 **공격형** | Tier 2~3 집중, 호황 시 공격적 매입, 고수익 추구 | 높음 | 현금 20% 이하까지 공격 매입 |
| 🎯 **지배형** | 한 섹터 올인, 지배력 보너스 극대화 | 중간 | 목표 섹터에 80%+ 집중 |
| 🎲 **기회형** | hot 섹터 추격매수, 트렌드 전환 시 매각, 시세차익 | 높음 | 매각+매입 빈번, 현금 회전율 높음 |

### 전략별 의사결정 로직

#### 🏦 보수형 (Conservative)

```json
{
  "id": "conservative",
  "cashReserveRatio": 0.5,
  "preferredTiers": [1, 2],
  "maxSectorConcentration": 0.4,
  "sellTrigger": {
    "sectorTrend": "cold",
    "holdingTurns": 5
  },
  "eventBias": "safe"
}
```

- **매입 조건**: `cash × (1 - cashReserveRatio) ≥ assetCost`
- **매각 조건**: 보유 섹터가 cold로 전환 + 5턴 이상 보유
- **이벤트 대응**: 항상 안전한 선택지 (비용이 적은 쪽)
- **정부 이벤트 대응**: 비용 최소화 우선

#### 🚀 공격형 (Aggressive)

```json
{
  "id": "aggressive",
  "cashReserveRatio": 0.2,
  "preferredTiers": [2, 3],
  "maxSectorConcentration": 0.6,
  "buyTrigger": {
    "marketState": "boom",
    "sectorTrend": "hot"
  },
  "eventBias": "reward"
}
```

- **매입 조건**: boom + hot일 때 현금 80%까지 투입
- **매각 조건**: recession 진입 시 Tier 3 자산 선제 매각
- **이벤트 대응**: 보상이 큰 선택지 우선 (비용 감수)
- **정부 이벤트 대응**: 기회가 되면 적극 참여

#### 🎯 지배형 (Dominator)

```json
{
  "id": "dominator",
  "cashReserveRatio": 0.3,
  "targetSectors": 1,
  "sectorSelectionMethod": "highest_flow_rate",
  "maxSectorConcentration": 1.0,
  "eventBias": "sector_aligned"
}
```

- **섹터 선택**: 게임 시작 시 유입량이 가장 높은 섹터 선택 (시드 기반)
- **매입 조건**: 목표 섹터 자산만 매입, Tier 1→2→3 순서
- **매각 조건**: 목표 섹터 외 자산만 매각 (이벤트로 획득 시)
- **이벤트 대응**: 목표 섹터와 관련된 선택지 우선

#### 🎲 기회형 (Opportunist)

```json
{
  "id": "opportunist",
  "cashReserveRatio": 0.3,
  "preferredTiers": [1, 2],
  "trendChaseThreshold": "hot",
  "sellOnCold": true,
  "holdingTurnsMax": 4,
  "eventBias": "contextual"
}
```

- **매입 조건**: hot 섹터에 진입, neutral 이상이면 유지
- **매각 조건**: cold 전환 즉시 매각 또는 4턴 이상 보유 시 매각
- **이벤트 대응**: 현재 포트폴리오와 시장 상태에 따라 동적 판단
- **정보 활용**: 조사로 트렌드를 파악한 후 선매입/선매각

## AI 조사 시스템

### 변경: 정보 섹터 기반 조사

AP 삭제 후 조사는 **정보 섹터 자산 보유**로 해금. 기존 "AP 1 소모" → "정보 자산 1개당 1회/턴 조사 가능".

| 항목 | 값 |
|------|-----|
| 조사 해금 조건 | 정보 섹터 자산 보유 |
| 조사 횟수 | 보유 정보 자산 1개당 1회/턴 |
| 조사 비용 | 없음 (자산 보유가 비용) |
| 조사 대상 | 플레이어가 선택 (AI는 전략에 따라 자동 선택) |

### 공개 정보 (무료)

| 정보 | 표시 위치 |
|------|----------|
| 순위 + 순자산 | 현황판 |
| 보유 섹터 (개수만) | 현황판 |
| 전략 힌트 ("공격적 행보") | 현황판 |
| 글로벌 시장 상태 | GameHeader |
| 순위 변동 (▲▼─) | 현황판 |
| 정부 정책 현황 | 정부 탭 |

### 비밀 정보 (정보 자산 보유 시 조사)

| 조사 대상 | 얻는 정보 | 전략적 가치 |
|----------|----------|------------|
| 섹터 트렌드 | 다음 턴 방향 | 매입/매각 타이밍 |
| 경쟁사 포트폴리오 | 특정 기업 보유 자산 전체 | 지배권 경쟁 판단 |
| 경쟁사 전략 | 전략 타입 정확히 공개 | 다음 행동 예측 |
| 섹터 점유율 | 정확한 수익 분배 비율 | 진입 가치 판단 |
| 시장 풀 현황 | 섹터별 유입량 + 잔여 풀 | 거시 전략 |

### AI의 조사 행동

AI는 전략 타입에 따라 조사 대상을 자동 결정:

| 전략 | 우선 조사 대상 | 이유 |
|------|-------------|------|
| 보수형 | 섹터 트렌드 → 시장 풀 | 리스크 회피를 위한 전망 파악 |
| 공격형 | 섹터 트렌드 → 섹터 점유율 | 고수익 섹터 진입 판단 |
| 지배형 | 경쟁사 포트폴리오 → 섹터 점유율 | 지배권 경쟁 상대 파악 |
| 기회형 | 섹터 트렌드 → 경쟁사 전략 | 트렌드 선점 + 경쟁 회피 |

## AI 이벤트 대응

### 이벤트 타입별 AI 행동

이벤트는 매 턴 고정 1개 + 추가 확률로 발생. 3가지 타입:

| 타입 | 비중 | AI 대응 원칙 |
|------|------|-------------|
| 기회형 | 50% | 전략에 따라 수용/거부 |
| 선택형 | 30% | 전략 bias에 따라 선택 |
| 압박형 | 20% | 손실 최소화 우선 |

### 전략별 이벤트 대응 매트릭스

```
eventBias 결정 로직:

conservative.eventBias = "safe"
  → 기회형: 비용 < cash × 0.2이면 수용, 아니면 거부
  → 선택형: 항상 비용이 적은 쪽
  → 압박형: 비용이 적은 쪽

aggressive.eventBias = "reward"
  → 기회형: 비용 < cash × 0.5이면 수용
  → 선택형: 보상이 큰 쪽 (비용 감수)
  → 압박형: 현금 여유 시 비용 투자해 피해 최소화

dominator.eventBias = "sector_aligned"
  → 기회형: 목표 섹터 관련이면 수용
  → 선택형: 목표 섹터에 유리한 쪽
  → 압박형: 목표 섹터 보호 우선

opportunist.eventBias = "contextual"
  → 기회형: 현재 시장 상태 + 트렌드 기반 동적 판단
  → 선택형: 단기 이익 극대화
  → 압박형: 포트폴리오 손실 최소화
```

### 특성(Trait) 대응

이벤트로 특성이 부여/제거될 때 AI 행동 조정:

| 특성 예시 | AI 반응 |
|----------|---------|
| "세금 감면" (소득 +10%) | 공격형: 추가 매입 가속 / 보수형: 현금 비축량 상향 |
| "규제 대상" (매입비용 +15%) | 모든 전략: 해당 섹터 매입 보류 |
| "시장 신뢰" (영향력 +2/턴) | 지배형: 영향력 활용해 추가 투자 |
| "부채 경고" (이자율 ×1.5) | 보수형: 즉시 부채 상환 / 공격형: 자산 매각 검토 |

특성은 항상 선택권이 있으므로, AI는 `eventBias`에 따라 특성 수용/거부를 결정한다.

## AI 정부 이벤트 대응

정부 이벤트는 매 턴 1개 고정 발생. 인플레이션(가격+소득 복리 상승)이 기본 환경.

### AI의 정부 이벤트 전략

| 전략 | 인플레이션 대응 | 정부 이벤트 대응 |
|------|-------------|---------------|
| 보수형 | 현금 가치 하락 인지 → 안전 자산 선매입 | 비용 최소화 선택 |
| 공격형 | 인플레이션을 레버리지로 활용 → 부채 매입 | 투자 기회 포착 |
| 지배형 | 목표 섹터 자산 가격 상승 전 매입 완료 | 섹터 보호 우선 |
| 기회형 | 인플레이션 수혜 섹터 탐색 | 상황에 따라 동적 |

## 턴 처리 순서

```
턴 시작
│
├── 자유 행동 Phase (Free Action)
│   ├── Human: UI에서 행동 선택 (현금 기반, 무제한)
│   ├── AI: 전략 패턴이 행동 결정 (현금 기반)
│   │   ├── 매입/매각/업그레이드 반복
│   │   ├── 조사 (정보 자산 보유 시, 1개당 1회/턴)
│   │   └── 현금 부족 또는 전략 판단으로 종료
│   └── 모든 Company의 Action[] 수집
│
├── 정부 Phase (Government)
│   ├── 인플레이션 적용 (가격+소득 복리)
│   └── 정부 이벤트 1개 (매 턴 고정)
│       └── 모든 Company 대응 (human: UI, AI: 전략 기반)
│
├── 이벤트 Phase (Event)
│   ├── 고정 이벤트 1개 (매 턴)
│   ├── 추가 이벤트 (확률 기반)
│   ├── 타입: 기회형(50%) / 선택형(30%) / 압박형(20%)
│   ├── 모든 Company 선택 → 효과 동시 적용
│   └── 특성 부여/제거 처리
│
├── 정산 Phase (Settlement)
│   ├── 시장 풀 → 섹터별 수익 분배 (점유율)
│   ├── 지배력 재계산 (전체 Company)
│   ├── 영향력 감소 (전체 Company)
│   ├── 부채 이자 계산 (마이너스 Company)
│   ├── 순위 갱신
│   └── 화폐 보존 검증 (assert)
│
└── 결과 Phase (Result)
    ├── 상세 결과 (내 기업)
    ├── 요약 알림 (경쟁사 주요 행동)
    └── 순위 변동
```

### 행동 순서의 긴장감

행동이 시드 RNG로 셔플된 순서대로 처리됨:
- 내가 사려던 자산을 경쟁사가 먼저 매입 가능
- 섹터 수요에 따라 순서대로 가격 상승
- 매 턴 "이번엔 내가 먼저일까?" → 시드 기반 운 요소

## 경제 모델: 시장 풀 기반

### 초기 화폐 분배

```
플레이어:         $1,000
경쟁사 3개:       $3,000 ($1,000 × 3)
시장 풀:         $20,000
─────────────────────────
총계:            $24,000 (런 내내 불변)
```

### 자산 소득 = 점유율 기반 분배

```
섹터 유입량 = marketPool × sectorFlowRate × marketMultiplier × trendMultiplier
내 점유율   = 내 섹터 자산 가치 / 섹터 총 자산 가치 (전체 Company)
내 소득     = floor(섹터 유입량 × 내 점유율 × dominanceMultiplier)
```

- 인플레이션에 의해 소득도 복리로 상승 (정부 시스템 연동)
- 경쟁사가 같은 섹터에 있으면 파이를 나눠야 함
- 섹터 독점 = 파이 독식 (지배력 보너스와 시너지)

### 돈의 흐름

```
시장 풀 → 섹터 유입 → 점유율 분배 → 각 Company
각 Company → 매입 비용 → 시장 풀
각 Company → 생활비/지출 → 시장 풀
각 Company → 이벤트 비용 → 시장 풀
시장 풀 → 이벤트 보상 → 각 Company
각 Company → 매각 → 시장 풀 → 매각 대금 → Company
각 Company → 부채 이자 → 시장 풀
```

## 유기적 상호작용 (5가지)

### ① 섹터 수요 효과

경쟁사의 투자가 해당 섹터 자산 가격에 영향:

- 투자 집중 섹터 → 매입 비용 프리미엄 (+10~20%)
- 경쟁사 매각 시 → 가격 하락 (매수 기회)
- 인플레이션으로 가격이 턴마다 복리 상승

### ② 지배력 경쟁

- 섹터당 지배자는 1명만 (순자산 기준 우선권)
- 경쟁사가 지배 중인 섹터 진입 시 프리미엄 추가
- 지배권 역전 가능

### ③ 이벤트 파급

- 모든 Company가 이벤트에 대응 (human: UI 선택, AI: 전략 기반)
- 경쟁사의 선택이 시장에 파급:
  - 보수형이 금융위기 때 전부 매각 → 시장 추가 하락
  - 공격형이 기술혁신 때 올인 → 기술 섹터 과열
- 특성 부여/제거가 전체 Company에 영향

### ④ 순위 효과

- 1위: 영향력 +2/턴 (시장 주목)
- 꼴찌: 이벤트에서 "역전 기회" 선택지 해금

### ⑤ 정부 시스템 영향

- 인플레이션은 모든 Company에 동일 적용
- 정부 이벤트 대응에 따라 Company 간 격차 확대/축소
- AI는 전략에 맞게 정부 이벤트에 자동 대응

## 파산 처리

### 마이너스 허용 + 이자 페널티

AP 삭제 후 현금이 유일한 행동 자원이므로, 마이너스를 허용하되 페널티를 부과한다.

| 상태 | 조건 | 효과 |
|------|------|------|
| 정상 | cash ≥ 0 | 일반 플레이 |
| 부채 | cash < 0 | 매 턴 이자 페널티 (부채 × 이자율) |
| 파산 | cash < -파산기준 **이고** 매각 가능 자산 없음 | 런에서 탈락 |

```
이자 페널티 = abs(cash) × DEBT_INTEREST_RATE (매 턴 정산 시)
```

- AI도 동일한 파산 규칙 적용
- 부채 상태의 AI는 전략과 무관하게 자산 매각 우선
- 파산한 경쟁사는 런에서 제거 (남은 자산 시장 풀로 환수)

## 승리 조건

### 순자산 1위 = 승리

30턴 종료 시 순자산 1위인 Company가 승리. 플레이어와 AI 동일 기준.

```
순자산 = cash + Σ(보유 자산 현재가치) - debt
```

### 목표 시스템 (보너스 가산)

런 시작 시 3개 목표 중 1개를 선택. 달성 시 순자산에 보너스 가산.

| 목표 타입 | 예시 | 보너스 |
|----------|------|--------|
| 섹터 지배 | "기술 섹터 지배자 달성" | +$2,000 |
| 영향력 | "영향력 80 이상 도달" | +$1,500 |
| 다각화 | "4개 이상 섹터에 자산 보유" | +$1,000 |

- 목표는 런 시작 시 3개가 랜덤 제시, **1개만 선택**
- AI도 동일하게 3개 중 1개를 선택 (전략 타입에 맞는 목표 우선)
- 목표 달성 보너스는 최종 순자산에 가산되어 순위에 반영

### AI의 목표 선택

| 전략 | 우선 목표 | 이유 |
|------|----------|------|
| 보수형 | 다각화 | 분산 투자와 일치 |
| 공격형 | 영향력 | 적극적 행동으로 영향력 축적 |
| 지배형 | 섹터 지배 | 전략 자체가 섹터 집중 |
| 기회형 | 다각화 / 영향력 | 상황에 따라 유연하게 |

## 난이도 시스템

### 난이도 레벨

| 레벨 | 이름 | AI 현금 보정 | AI 판단 정확도 | 정보 활용 |
|------|------|------------|-------------|----------|
| 1 | 쉬움 | ×0.8 | 60% | 조사 안 함 |
| 2 | 보통 | ×1.0 | 80% | 기본 조사 |
| 3 | 어려움 | ×1.2 | 95% | 적극 조사 |
| 4 | 극한 | ×1.5 | 100% | 완벽 정보 |

### 판단 정확도

AI가 "최적 행동"을 선택할 확률. 나머지 확률로 차선/랜덤 행동.

```typescript
function aiDecide(strategy: CompetitorStrategy, state: GameState, accuracy: number): Action[] {
  const optimal = strategy.decide(state, company);
  if (rng() < accuracy) return optimal;
  return addNoise(optimal, rng);  // 일부 행동을 랜덤으로 교체
}
```

### 난이도별 AI 특성

| 난이도 | 매입 타이밍 | 이벤트 대응 | 조사 행동 |
|--------|-----------|-----------|----------|
| 쉬움 | 랜덤 지연 (1~3턴 느림) | 50% 확률로 비최적 선택 | 조사 안 함 |
| 보통 | 정상 | 전략 bias 따름 | 정보 자산 1개 시 조사 |
| 어려움 | 트렌드 선행 (hot 전환 전 매입) | 최적에 가까운 선택 | 정보 자산 우선 확보 |
| 극한 | 완벽 타이밍 + 현금 보정 | 항상 최적 | 완벽 정보 (조사 없이도 모든 정보 접근) |

## 7섹터 체제와 AI

### 섹터 구성

7섹터: 외식 / 기술 / 부동산 / 물류 / 에너지 / 금융 / 정보

**정보 섹터**는 단일 자산 타입 (Tier 구분 없음):

| 섹터 | 자산 |
|------|------|
| **정보** | 정보 기업 (단일 타입, Tier 무관) |

정보 섹터의 고유 역할:
- **조사 해금**: 정보 자산 보유 시 조사 가능 (1개당 1회/턴)
- **Tier 차등 없음**: 정보 기업은 1종류만 존재, 매입 비용/수익 고정
- **수익은 낮음**: 다른 섹터 대비 baseIncome 낮음 (정보의 가치는 간접적)
- **전략적 가치**: 트렌드 선행 정보 → 매입/매각 타이밍 → 간접 수익

### AI의 정보 섹터 활용

| 전략 | 정보 자산 매입 우선순위 | 이유 |
|------|---------------------|------|
| 보수형 | 낮음 | 직접 수익 우선, 조사는 선택적 |
| 공격형 | 중간 | Tier 1 정보 자산으로 트렌드 파악 후 공격 매입 |
| 지배형 | 낮음 | 목표 섹터에 올인, 정보는 부차적 |
| 기회형 | 높음 | 트렌드 선점이 핵심 전략 |
