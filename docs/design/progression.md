# 진행 시스템 상세 기획

> 영향력, 섹터 지배, 특성, 목표, 승리/파산 — 플레이어 성장과 런 평가의 모든 것.

---

## 영향력 (Influence) 시스템

### 디자인 의도

영향력은 **플레이어의 시장 내 존재감**을 수치화한다. 자산 매입으로 영향력이 오르고, 아무것도 안 하면 자연 감소한다. 높은 영향력은 매입 할인, 이벤트 보너스 등 간접적 이점을 제공한다.

핵심 감정: **"나는 이 시장에서 점점 큰 손이 되고 있다"**

### 수치

| 항목 | 값 |
|------|-----|
| 범위 | 0~100 |
| 시작값 | 0 (메타 '인맥' 업그레이드로 증가) |
| 자연 감소 | -1/턴 (`INFLUENCE_DECAY_PER_TURN`) |
| 매입 시 증가 | Tier 1: +2, Tier 2: +3, Tier 3: +5 |
| 섹터 지배 달성 | +10 (`INFLUENCE_DOMINANCE_BONUS`) |
| 이벤트 | 선택지에 따라 -15 ~ +20 |

### 5단계 영향력 티어

| 구간 | 타이틀 | 매입 할인 | 이벤트 보너스 |
|------|--------|----------|-------------|
| 0~19 | 무명 투자자 | 0% | 0% |
| 20~39 | 주목받는 투자자 | 0% | 5% |
| 40~59 | 영향력 있는 투자자 | 5% | 10% |
| 60~79 | 시장의 큰 손 | 10% | 15% |
| 80~100 | 자본가 | 15% | 20% |

### 영향력 경제

**획득 속도 분석** (매입만으로):
- Tier 1 매입 1개 = +2 영향력
- 30턴간 자연 감소 = -30 영향력
- 영향력 40 도달: ~20회 Tier 1 매입 필요 (자연 감소 상쇄 포함)
- 현실적으로는 **Tier 2~3 매입 + 이벤트 보너스 조합**이 필수

**유지 비용**:
- 영향력 80(자본가) 유지: 매턴 -1이므로 2~3턴마다 매입 1회 필요
- 후반부에 매입할 자산이 없으면 자연 감소로 티어 하락

### 전략

- **초반 (1~10턴)**: 영향력은 자연스럽게 낮음. 현금 투자에 집중.
- **중반 (11~20턴)**: 영향력 40 목표. 매입 할인 해금이 핵심 목표.
- **후반 (21~30턴)**: 영향력 60~80 유지. 매입 할인 + 이벤트 보너스 활용.

## 섹터 지배 (Dominance) 시스템

### 디자인 의도

같은 섹터에 집중 투자하면 **규모의 경제**를 체험한다. 지배력은 "분산 vs 집중" 딜레마의 핵심.

핵심 감정: **"이 섹터는 내 것이다"**

### 6섹터 체계

| 섹터 | 특성 | Tier 1~3 |
|------|------|----------|
| 외식 | 저비용 진입, 안정 | 포장마차 → 레스토랑 → 프랜차이즈 |
| 기술 | 고성장, 고변동 | 앱 스타트업 → SaaS 기업 → 테크 대기업 |
| 부동산 | 불황 내성, 규제 리스크 | 원룸 임대 → 상가 건물 → 오피스 타워 |
| 유통 | 중간 리스크/리턴 | 편의점 → 마트 체인 → 대형 유통사 |
| 금융 | 고수익, 극단 변동 | P2P 대출 → 투자 펀드 → 은행 지분 |
| **정보** | 조사 특화, 정보 우위 | *(별도 설계)* |

> 정보 섹터는 Phase 2에서 추가. 조사 행동과 연계되는 특수 섹터.

### 3단계 등급

| 같은 섹터 보유 수 | 등급 | 소득 보너스 | 특수 효과 |
|-----------------|------|-----------|----------|
| 1개 | 진입자 (entrant) | ×1.0 | 없음 |
| 2개 | 경쟁자 (competitor) | ×1.1 (+10%) | 없음 |
| 3개+ | 지배자 (dominant) | ×1.25 (+25%) | 이벤트 제3 선택지 해금 |

### 분산 vs 집중 트레이드오프

**집중 투자 (외식 3개)**:
- 비용: $300 (포장마차 ×3)
- 지배 보너스: 소득 ×1.25
- 리스크: 외식 cold 시 전체 포트폴리오 타격

**분산 투자 (다른 Tier 1 × 3개)**:
- 비용: ~$370
- 보너스: 없음
- 리스크: 분산되어 섹터 리스크 감소

→ 비용 효율은 집중이 우세, 리스크는 분산이 우세. **지배자 이벤트 C 선택지가 진짜 가치.**

## 특성 (Trait) 시스템

### 디자인 의도

특성은 **이벤트를 통해서만 획득/제거**되는 영구 수식어다. 런 내내 플레이어의 전략적 정체성을 형성하며, 같은 이벤트라도 선택에 따라 다른 특성을 얻어 매 런이 고유해진다.

핵심 감정: **"내 선택이 쌓여서 나만의 투자 스타일을 만든다"**

### 핵심 규칙

| 규칙 | 설명 |
|------|------|
| 획득 경로 | **이벤트 선택지 전용**. 매입/매각/업그레이드로는 획득 불가 |
| 지속 시간 | **영구**. 런이 끝날 때까지 유지 (턴 제한 없음) |
| 선택권 보장 | 특성 부여/제거는 **항상 플레이어의 선택**. 강제 부여 없음 |
| 중복 | 같은 특성 중복 불가 |
| 상한 | 동시 보유 상한 없음 (밸런스 테스트 후 결정) |

### 특성 효과 구조 (JSON 선언형)

특성의 효과는 **데이터로 선언**하고, 엔진이 해석한다. 로직을 하드코딩하지 않는다.

```jsonc
{
  "id": "market-insider",
  "name": "시장 내부자",
  "description": "시장 정보에 정통하다",
  "effects": [
    { "type": "incomeMultiplier", "value": 1.1 },
    { "type": "investigationDiscount", "value": 0.5 }
  ],
  "source": "event:partnership-offer:A",
  "removable": true
}
```

### 효과 타입

| effect type | 설명 | value 예시 |
|-------------|------|-----------|
| `incomeMultiplier` | 전체 소득에 곱셈 배율 | `1.1` = +10% |
| `expenseMultiplier` | 전체 지출에 곱셈 배율 | `0.9` = -10% |
| `purchaseDiscount` | 매입 비용 할인 | `0.1` = 10% 할인 |
| `influenceGainBonus` | 영향력 획득량 추가 | `2` = +2 추가 |
| `influenceDecayReduction` | 영향력 자연 감소 경감 | `0.5` = 50% 감소 |
| `sectorIncomeMultiplier` | 특정 섹터 소득 배율 | `{ "sector": "tech", "value": 1.2 }` |
| `investigationDiscount` | 조사 비용 할인 | `0.5` = 50% 할인 |
| `eventBonusMultiplier` | 이벤트 보상 배율 | `1.15` = +15% |
| `interestReduction` | 파산 이자율 경감 | `0.5` = 이자 50% 감소 |

### 특성 예시

| ID | 이름 | 효과 | 획득 이벤트 |
|----|------|------|-----------|
| `market-insider` | 시장 내부자 | 소득 +10%, 조사 비용 -50% | 파트너십 제안 A |
| `crisis-profiteer` | 위기 수익가 | 불황 시 소득 +20% | 금융 위기 C |
| `media-darling` | 미디어 총아 | 영향력 획득 +3, 감소 -50% | 미디어 스캔들 A |
| `cost-cutter` | 비용 절감가 | 지출 -15% | 세무 조사 A |
| `sector-specialist` | 섹터 전문가 | 지배 섹터 소득 +15% | 기술 혁신 C |
| `debt-manager` | 부채 관리자 | 파산 이자율 50% 경감 | 금융 위기 A |
| `aggressive-investor` | 공격적 투자자 | 매입 할인 +10%, 매각 효율 -10% | 경기 부양책 A |
| `cautious-saver` | 신중한 저축가 | 지출 -10%, 소득 -5% | 경기 부양책 B |

### 특성 제거

일부 이벤트 선택지는 기존 특성을 **제거**한다. 제거도 플레이어의 선택이다.

```jsonc
// 이벤트 선택지에서 특성 제거 예시
{
  "choiceId": "B",
  "label": "전략 전환",
  "effects": { "money": -100 },
  "removeTrait": "cautious-saver",
  "grantTrait": "aggressive-investor"
}
```

→ "신중한 저축가"를 버리고 "공격적 투자자"로 전환. 항상 플레이어가 선택지를 고른 결과.

### 데이터/로직 분리 원칙

```
data/traits.json          ← 특성 정의 (id, name, effects[])
src/game/schema/trait.ts   ← JSON → TypeScript 타입 변환, validation
src/game/engine.ts         ← effects[] 해석, 배율 적용
```

- 특성 추가/수정은 **JSON 편집만으로** 가능
- 새 effect type 추가 시에만 엔진 코드 수정 필요
- schema 레이어가 런타임 validation 담당

## 목표 (Goal) 시스템

### 디자인 의도

목표는 **런의 방향성**을 제시한다. 매 런 시작 시 제시된 목표 중 3개를 선택하면, 달성 시 순자산에 보너스가 가산된다. 같은 맵(시드)이라도 목표 선택에 따라 전략이 달라진다.

핵심 감정: **"이번 런의 미션이 있다"**

### 핵심 규칙

| 규칙 | 설명 |
|------|------|
| 선택 시점 | **런 시작 시** (턴 1 이전) |
| 선택 수 | **3개** (제시된 목표 풀에서 선택) |
| 보상 | 달성 시 **순자산 보너스 가산** (승리 판정에 반영) |
| 부분 달성 | 없음. 달성 or 미달성 (binary) |
| 변경 | 런 중 변경 불가 |

### 목표 유형

#### 경제 목표

| ID | 이름 | 조건 | 보너스 |
|----|------|------|--------|
| `net-worth-10k` | 만달러 클럽 | 순자산 $10,000 이상으로 런 종료 | +$2,000 |
| `net-worth-50k` | 대자본가 | 순자산 $50,000 이상으로 런 종료 | +$8,000 |
| `cash-hoarder` | 현금 왕 | 현금 $5,000 이상 보유한 채 런 종료 | +$3,000 |
| `no-debt` | 무차입 경영 | 런 전체 동안 현금 마이너스 없이 완주 | +$2,500 |

#### 섹터 목표

| ID | 이름 | 조건 | 보너스 |
|----|------|------|--------|
| `sector-dominator` | 섹터 지배자 | 2개 이상 섹터에서 지배자 달성 | +$4,000 |
| `sector-diversifier` | 분산 투자자 | 4개 이상 섹터에 자산 보유 | +$3,000 |
| `tech-mogul` | 기술 재벌 | 기술 섹터 3개 보유 + 기술 hot 상태에서 런 종료 | +$3,500 |
| `finance-king` | 금융 왕 | 금융 섹터 지배 + 순자산 1위 | +$5,000 |

#### 영향력 목표

| ID | 이름 | 조건 | 보너스 |
|----|------|------|--------|
| `capitalist` | 자본가 도달 | 영향력 80 이상 달성 (런 종료 시) | +$3,000 |
| `influence-maintainer` | 영향력 유지 | 영향력 60 이상을 10턴 연속 유지 | +$4,000 |

#### 스토리 목표

| ID | 이름 | 조건 | 보너스 |
|----|------|------|--------|
| `crisis-survivor` | 위기 생존자 | 불황(recession) 중에 순자산 증가 달성 | +$3,500 |
| `from-nothing` | 맨손 성공기 | 메타 업그레이드 0인 상태에서 순자산 $20,000 달성 | +$6,000 |
| `trait-collector` | 특성 수집가 | 특성 5개 이상 보유한 채 런 종료 | +$2,500 |
| `event-master` | 이벤트 마스터 | 이벤트 선택지 C를 3회 이상 선택 | +$3,000 |

### 목표 선택 UI 흐름

```
[런 시작] → 목표 풀 제시 (6~8개) → 플레이어가 3개 선택 → [턴 1 시작]
```

- 목표 풀은 **시드 RNG**로 결정 (같은 시드 = 같은 목표 풀)
- 선택한 목표는 게임 중 **상단 바 또는 현황 탭**에서 항상 확인 가능
- 달성 시 시각적 피드백 (체크 표시, 보너스 금액 표시)

### 보너스 적용

```
최종 순자산 = 기본 순자산 + Σ(달성한 목표의 보너스)
```

목표 보너스는 **런 종료 시 순자산에 가산**된다. 승리 판정(순자산 1위)에 직접 반영되므로, 경쟁사보다 순자산이 낮더라도 목표 보너스로 역전이 가능하다.

## 승리 시스템

### 디자인 의도

승리 조건은 단순 명료하다: **순자산 1위**. 점수 공식이 아니라 순자산만으로 승패를 가린다. 목표 보너스가 유일한 가산 요소.

핵심 감정: **"결국 가장 부유한 자가 이긴다"**

### 승리 조건

```
승리 조건 = (내 최종 순자산) > max(경쟁사별 순자산)
```

| 항목 | 정의 |
|------|------|
| 기본 순자산 | 현금 + Σ(보유 자산 현재가치) |
| 목표 보너스 | Σ(달성한 목표의 보너스) |
| **최종 순자산** | **기본 순자산 + 목표 보너스** |
| 승리 판정 | 최종 순자산이 모든 경쟁사보다 높으면 승리 |

### 동점 처리

최종 순자산이 동일한 경우:

| 우선순위 | 기준 |
|----------|------|
| 1 | 최종 순자산 (높을수록 우선) |
| 2 | 영향력 (높을수록 우선) |
| 3 | 지배 섹터 수 (많을수록 우선) |
| 4 | 달성 목표 수 (많을수록 우선) |

### 런 결과 화면

```
┌─────────────────────────────────┐
│          🏆 런 결과              │
│                                 │
│  1위  ⭐ 내 기업    $52,400     │
│       목표 보너스   +$9,000     │
│       최종 순자산   $61,400     │
│                                 │
│  2위  🏦 한강투자   $58,200     │
│  3위  🚀 밀레니엄   $41,100     │
│  4위  🎯 청담캐피탈  $33,800    │
│                                 │
│  달성 목표: 2/3                  │

```

## 파산 시스템

### 디자인 의도

현금이 마이너스가 되어도 **즉시 게임오버가 아니다**. 대신 마이너스 잔고에 대해 **이자 페널티**가 매턴 부과된다. 부채를 안고 위험하게 플레이할지, 자산을 매각해 부채를 청산할지 선택하는 긴장감.

핵심 감정: **"빚이 늘어나지만… 이 자산만 있으면 역전할 수 있다"**

### 핵심 규칙

| 규칙 | 설명 |
|------|------|
| 마이너스 허용 | 현금이 0 이하가 되어도 런 계속 |
| 이자 부과 | 매턴 마이너스 잔고의 일정 비율을 추가 차감 |
| 파산 조건 | **현금 < 0** 이고 **매각 가능 자산 = 0** 이고 **순자산 < 0** |
| 파산 결과 | 즉시 런 종료 (최하위 처리) |

### 이자 계산

```
이자 = floor(abs(현금) × DEBT_INTEREST_RATE)
```

| 상수 | 값 | 설명 |
|------|-----|------|
| `DEBT_INTEREST_RATE` | 0.10 (10%) | 매턴 마이너스 잔고의 10% 추가 차감 |

### 부채 시나리오

```
턴 15: 현금 -$200, 자산 가치 $3,000
  → 이자: $200 × 10% = -$20 추가 차감
  → 턴 16 시작 시 현금: -$200 - $20 + 소득
  → 순자산: $3,000 - $220 = $2,780 (양수 → 게임 계속)

턴 20: 현금 -$1,500, 자산 가치 $1,200
  → 이자: $1,500 × 10% = -$150 추가 차감
  → 순자산: $1,200 - $1,650 = -$450 (음수)
  → 매각 가능 자산 있음 → 게임 계속 (매각 강제는 아님)

턴 22: 현금 -$2,000, 자산 0개
  → 순자산 < 0, 매각 불가 → 🔴 파산
```

### 이자와 특성 상호작용

- `debt-manager` (부채 관리자) 특성: 이자율 50% 경감 (10% → 5%)
- `cautious-saver` (신중한 저축가) 특성: 지출 감소로 부채 진입 방지
- 인플레이션(정부 시스템)과 이자가 동시에 적용 → 부채 상태에서 인플레이션은 치명적

### 파산 방지 전략

| 전략 | 설명 |
|------|------|
| 즉시 매각 | 마이너스 진입 직후 저가 자산 매각으로 현금 확보 |
| 이자 최소화 | 마이너스 금액을 최소로 유지 (큰 지출 회피) |
| `debt-manager` 특성 | 이자율 50% 경감으로 부채 부담 완화 |
| 고소득 유지 | 소득 > 이자 + 지출이면 자연 회복 가능 |

## 시스템 간 상호작용

### 특성 ↔ 이벤트

이벤트가 특성의 **유일한 획득/제거 경로**. 이벤트 선택이 곧 특성 빌드.

```
이벤트 발생 → 선택지 A/B/C → 선택지에 따라 특성 부여/제거
                              ↓
                     특성 효과가 다음 턴부터 적용
                              ↓
                     이후 이벤트 선택에 영향 (특성에 따라 유불리)
```

### 목표 ↔ 전략

목표 선택이 런의 전략 방향을 결정한다.

| 목표 조합 예시 | 유도되는 전략 |
|--------------|-------------|
| 섹터 지배자 + 기술 재벌 + 자본가 도달 | 기술 섹터 올인 + 영향력 관리 |
| 현금 왕 + 무차입 경영 + 분산 투자자 | 보수적 분산 투자 |
| 위기 생존자 + 금융 왕 + 대자본가 | 금융 지배 + 위기 활용 고위험 전략 |
| 맨손 성공기 + 특성 수집가 + 이벤트 마스터 | 메타 없이 이벤트 중심 플레이 |

### 파산 ↔ 승리

마이너스를 허용하면서 이자 페널티를 부과하는 구조는 **역전 가능성**을 열어둔다.

```
현금 마이너스 → 이자 누적 → 자산 가치가 이자를 상쇄?
  → Yes: 부채 안고 자산 유지 → 후반 가치 상승으로 역전 가능
  → No:  자산 매각 → 소득 감소 → 하향 나선 → 파산 위기
```

### 영향력 ↔ 지배력 ↔ 특성

세 시스템이 상호 강화하는 피드백 루프:

| 시작 | 경로 | 결과 |
|------|------|------|
| 섹터 집중 매입 | → 지배자 달성 | → 이벤트 C 선택지 해금 |
| 이벤트 C 선택 | → 높은 보상 + 특성 획득 | → 영향력 상승 + 소득 배율 증가 |
| 영향력 상승 | → 매입 할인 | → 더 많은 매입 가능 → 지배력 강화 |

→ 이 루프에 진입하면 후반부 폭발적 성장. 대신 한 섹터에 과도하게 집중한 리스크(cold 전환, 경쟁사 견제)가 밸런스 장치.
