## 자산 ROI 비교

### 시장/섹터 조합별 턴당 수익률

기본 ROI(중립)에 시장배율 × 섹터트렌드배율을 곱한 값.

#### Tier 1 자산 ROI (턴당 %)

| 자산 | 중립 | boom+hot | boom+cold | recession+hot | recession+cold |
|------|------|----------|-----------|---------------|----------------|
| 포장마차 | 8.0% | 12.5% | 6.7% | 7.1% | 4.8% |
| 앱 스타트업 | 8.0% | 16.6% | 4.5% | 5.2% | 1.4% |
| 편의점 | 8.3% | 14.1% | 4.7% | 5.1% | 1.7% |
| P2P 대출 | 8.3% | 16.2% | 2.5% | 3.2% | 0.8% |
| 원룸 임대 | 6.0% | 8.6% | 4.6% | 7.4% | 4.0% |

> boom+hot은 "최고의 순간", recession+cold는 "최악의 순간"

#### 핵심 발견

**최고 수익 조합**: P2P 대출 + boom + hot = 16.2%/턴
**최악 수익 조합**: P2P 대출 + recession + cold = 0.8%/턴 (사실상 0)
**가장 안정적**: 원룸 임대 — 최악에서도 4.0% (최고의 4.6배)
**가장 변동 큰**: P2P 대출 — 최고의 20배가 최악 (16.2% / 0.8%)

## 업그레이드 손익분기 분석

### 레벨별 손익분기 턴 수

업그레이드 비용을 추가 소득으로 나눈 값. **이 턴 수 내에 회수되면 이익**.

```
레벨 0→1 손익분기 = (원가 × 0.3) / (기본소득 × 0.25)
레벨 1→2 손익분기 = (원가 × 0.6) / (기본소득 × 1.25 × 0.25)
레벨 2→3 손익분기 = (원가 × 0.9) / (기본소득 × 1.5625 × 0.25)
```

| 자산 | ROI | Lv0→1 | Lv1→2 | Lv2→3 |
|------|-----|-------|-------|-------|
| 포장마차 (8%) | 8% | 15턴 | 24턴 | 29턴 |
| 앱 스타트업 (8%) | 8% | 15턴 | 24턴 | 29턴 |
| 편의점 (8.33%) | 8.3% | 14.4턴 | 23턴 | 28턴 |
| P2P 대출 (8.33%) | 8.3% | 14.4턴 | 23턴 | 28턴 |
| 원룸 임대 (6%) | 6% | 20턴 | 32턴 | 38턴 |

### 전략적 함의

- **레벨 1**: ROI 8%+ 자산은 15턴 이내 회수 → **15턴 이전 매입 자산은 반드시 레벨 1**
- **레벨 2**: 24턴 회수 → **6턴 이전 매입 자산만 가치 있음**
- **레벨 3**: 29턴 회수 → **게임 시작 턴 1에 매입한 자산만 본전** (매우 타이트)
- **부동산**: 20턴 회수로 레벨 1도 비효율적. 10턴 이전 매입 시에만 업그레이드 고려.

> **결론**: 업그레이드는 **초반 매입 + 높은 ROI 자산**에만 효율적. 후반 매입 자산은 업그레이드보다 새 자산 매입이 유리.

## 지배력 vs 분산 비교

### 시나리오: $600 예산으로 턴 1~30 플레이

#### A. 외식 지배 (포장마차 ×3 = $300, 나머지 업그레이드)

| 항목 | 값 |
|------|-----|
| 초기 투자 | $300 |
| 기본 소득 | $24/턴 × 1.25(지배) = $30/턴 |
| 남은 자금 | $300 → 업그레이드 3회 |
| 업그레이드 후 소득 | ~$47/턴 |
| 추가 이점 | 이벤트 C 선택지 (해당 없음: 외식은 C 없음) |
| 30턴 예상 총 소득 | ~$1,200 |

#### B. 분산 3섹터 (포장마차 + 편의점 + P2P = $400, 나머지 업그레이드)

| 항목 | 값 |
|------|-----|
| 초기 투자 | $400 |
| 기본 소득 | $33/턴 (보너스 없음) |
| 남은 자금 | $200 → 업그레이드 2회 |
| 업그레이드 후 소득 | ~$41/턴 |
| 추가 이점 | 섹터 리스크 분산 |
| 30턴 예상 총 소득 | ~$1,050 |

#### C. 금융 지배 (P2P ×3 = $540)

| 항목 | 값 |
|------|-----|
| 초기 투자 | $540 |
| 기본 소득 (boom) | $45 × 1.25 × 1.5 = $84/턴 |
| 기본 소득 (recession) | $45 × 1.25 × 0.3 = $17/턴 |
| 추가 이점 | 금융 위기 C: +$500, 금리 인상 C: +$150 |
| 리스크 | recession 시 소득 80% 감소 |

### 분석 결론

- **안정 추구**: 분산 B가 최선 (리스크 대비 적정 소득)
- **최대 소득 추구**: 금융 지배 C가 boom 시 최고 (recession 리스크 감수)
- **비용 효율**: 외식 지배 A가 가장 적은 자금으로 지배 달성
- **지배의 진짜 가치**: 소득 +25%보다 **이벤트 C 선택지**가 핵심 (금융 위기 C = +$500)

## 게임 궤적 시뮬레이션

### 시나리오 1: 보수적 플레이 (분산, 메타 0)

```
턴 1:  $1,000 → 편의점 매입($120) = $880, 소득 $10/턴
턴 3:  ~$885 → 포장마차 매입($100) = $785, 소득 $18/턴
턴 5:  ~$791 → 편의점 업그레이드($36) = $755, 소득 $22/턴
턴 8:  ~$796 → 원룸 임대 매입($200) = $596, 소득 $34/턴
턴 12: ~$688 → 레스토랑 매입($400) = $288, 소득 $62/턴
턴 15: ~$462 → 업그레이드 몇 회 = ~$350, 소득 $78/턴
턴 20: ~$690 → 추가 매입/업그레이드, 소득 $110/턴
턴 25: ~$1,040 → 소득 누적, 순자산 ~$4,500
턴 30: 순자산 ~$7,000, 영향력 ~40, 점수 ~8,000
```

### 시나리오 2: 공격적 플레이 (금융 집중, 메타 0)

```
턴 1:  $1,000 → P2P 대출 매입($180) = $820, 소득 $15/턴
턴 3:  ~$835 → P2P 대출 ×2 매입($180) = $655, 소득 $30/턴 + 지배(경쟁자)
턴 5:  ~$655 → P2P 대출 ×3 매입($180) = $475, 소득 $47/턴 + 지배(지배자)
턴 8:  boom이면 → 소득 $47 × 1.5 = $70/턴. recession이면 → $14/턴
턴 12: [boom 시나리오] 투자 펀드 매입, 소득 ~$120/턴
       [recession 시나리오] 현금 바닥, 파산 위기
턴 20: [boom] 순자산 ~$5,000, 은행 지분 매입 가능
       [recession] 순자산 ~$1,500, 회복 중
턴 30: [boom 많았으면] 순자산 ~$15,000, 점수 ~17,000
       [recession 많았으면] 순자산 ~$3,000, 점수 ~4,000
```

### 시나리오 3: 만렙 메타 플레이

```
턴 1:  $3,000 / 3 AP / 영향력 45 → 조사(무료) + 매입 2개
       SaaS($500) + 투자 펀드($550) = $1,950, 소득 $84/턴 × 1.4(메타) = $118/턴
턴 3:  ~$2,166 → 매입 2개 더, 소득 ~$180/턴
턴 5:  3개 자산 보유 → 1섹터 지배, 소득 ~$230/턴
턴 10: 6~8 자산, 2섹터 지배, 소득 ~$350/턴
턴 15: 순자산 ~$10,000, 소득 ~$500/턴
턴 20: 순자산 ~$20,000, 10+ 자산
턴 30: 순자산 ~$50,000, 3섹터 지배, 영향력 80+
       점수 ~55,000, 메타 화폐 440
```

→ 메타 만렙은 1런 만에 전체 업그레이드를 다시 살 수 있는 수준의 점수를 냄.

## 밸런스 이슈 분석

### 이슈 1: 부동산 ROI 함정

**현상**: 부동산은 가장 비싼 섹터(T1 $200, T3 $2,000)인데 ROI가 가장 낮음(4~6%).

**원인**: 부동산의 장점은 recession 내성(0.85~0.95)이지만, 이 장점이 높은 비용과 낮은 ROI를 상쇄하지 못함.

**영향**: 합리적 플레이어는 부동산을 거의 매입하지 않음. 5개 섹터 중 1개가 사실상 사용되지 않는 "함정 선택지".

**제안**:
- A) baseIncome 20% 증가: 원룸 $12→$15, 상가 $30→$36, 타워 $80→$96
- B) 비용 15% 감소: 원룸 $200→$170, 상가 $600→$510, 타워 $2,000→$1,700
- C) 고유 패시브 추가: "임대 수입은 시장 불황에도 감소하지 않음" (recession 배율 1.0 고정)

**심각도**: 중간 — 게임은 돌아가지만 전략 다양성 감소

---

### 이슈 2: 금융 극단적 변동성

**현상**: 은행 지분의 recession 배율이 0.1 → $126 소득이 $12.6으로 급락 (90% 감소).

**원인**: 금융 섹터의 `marketMultiplier.recession` 값이 0.1~0.3으로 극단적.

**영향**: 금융 집중 전략은 recession 1~2턴 만에 파산 위기. 리스크가 너무 극단적이라 **도박에 가까움**.

**제안**:
- A) recession 하한을 0.3으로 상향: P2P 0.3→0.3(유지), 펀드 0.2→0.3, 은행 0.1→0.3
- B) recession 하한을 0.4로 상향: 더 온건한 조정
- C) 현행 유지: "극단적 리스크"가 금융 섹터의 정체성. 단, 이 리스크를 UI에서 명확히 표시

**심각도**: 높음 — 은행 지분 0.1×는 체감상 "버그"처럼 느껴질 수 있음

---

### 이슈 3: 멀티태스킹 가성비 과도

**현상**: 메타 화폐 20으로 AP +1 (2→3 = 50% 행동력 증가). 다른 업그레이드 대비 압도적.

**원인**: 매턴 1회 추가 행동 × 30턴 = 30회 추가 행동. 이는 약 30× 매입/업그레이드 기회.

**영향**: 첫 런에서 무조건 멀티태스킹부터 구매 → 메타 진행의 "정답"이 하나뿐.

**제안**:
- A) 비용 20→40으로 증가: 2~3런 차 구매 가능 (진행 속도 조절)
- B) 2레벨로 분리: Lv1(비용 15) = 50% 확률 +1AP, Lv2(비용 30) = 확정 +1AP
- C) 현행 유지: "첫 번째로 사야 할 업그레이드"라는 명확한 목표가 초보자에게 좋을 수 있음

**심각도**: 낮음 — 밸런스 문제이지만 플레이어 경험을 크게 해치지는 않음

---

### 이슈 4: 영향력 점수 가중치 부족

**현상**: 영향력 1 = 20점. 순자산 $1 = 1점. 영향력 80(자본가)을 유지해도 $1,600 상당.

**원인**: 순자산이 수천~수만 달러인데 비해 영향력은 0~100으로 스케일이 작음.

**영향**: 영향력은 간접 효과(할인, 무료 조사)로만 의미 있고, 점수에서는 미미. 플레이어가 영향력 관리의 동기를 잃을 수 있음.

**제안**:
- A) 가중치 20→50: 영향력 80 = 4,000점 (순자산 $4,000 상당)
- B) 가중치 20→100: 영향력 80 = 8,000점 (전략적 가치 부여)
- C) 영향력 기반 보너스 추가: 영향력 × 순자산 × 0.001 같은 곱셈 보너스

**심각도**: 중간 — 영향력의 간접 효과는 충분하지만, 점수에서 존재감이 없음

---

### 이슈 5: 후반 복리 폭발

**현상**: 턴 25~30에 순자산이 급격히 증가. appreciation + 소득 복리 효과.

**원인**: 자산 가치가 매턴 (1+appreciation)배로 증가 (지수적). appreciation 5%인 테크 대기업은 10턴 보유 시 가치 1.63배.

**영향**: 게임 후반부가 "이미 결정된 결과를 지켜보는" 느낌. 초반에 자산을 많이 산 플레이어가 후반에 압도적으로 유리.

**제안**:
- A) 점진적 지출 증가: 턴이 진행될수록 BASE_EXPENSES 증가 (인플레이션)
- B) 자산 가치 상한: 원가의 3배 초과 시 appreciation 감소
- C) 현행 유지: "복리의 마법"이 게임의 핵심 판타지. 후반 폭발이 바로 "자본가" 체험

**심각도**: 낮음 — 이것이 의도된 게임 경험일 수 있음 (복리 판타지)
