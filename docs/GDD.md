# WebYouAreCapitalist - 게임 디자인 문서 (Phase 2)

> 턴제 경영 로그라이트 웹게임. 소액 투자자에서 시작해 30턴 안에 순자산 1위 자본가로 성장하라.

---

## 1. 게임 개요

| 항목 | 내용 |
|------|------|
| 장르 | 턴제 경영 로그라이트 |
| 플랫폼 | 웹 (모바일/PC 반응형) |
| 기술 스택 | React 19, TypeScript 5, Zustand 5, Tailwind CSS 3 |
| 1회 플레이 | 30턴 (약 10~15분) |
| 핵심 키워드 | 섹터 투자, 매매 타이밍, 인플레이션, 특성, 정보전 |

### 게임 컨셉

플레이어는 $3,000를 가진 소액 투자자다. **현금이 곧 행동력** — AP 없이 돈이 허락하는 한 무제한으로 행동한다. 7개 섹터(외식/기술/부동산/물류/에너지/금융/**정보**)에 구좌 단위로 투자하고, 포트폴리오 소득으로 성장한다. 각 섹터는 고유한 소득 특성(안정형/시장연동형/레버리지형 등)을 가지며, 시장 상황과 섹터 트렌드에 따라 매입가·매각가·평가액이 매 턴 변동한다. 매 턴 정부 정책이 인플레이션을 일으키고, 이벤트가 특성을 부여하며, AI 경쟁사 3곳과 순자산 1위를 다툰다. 30턴 후 **순자산 1위**가 승리.

**핵심 메시지: 현금을 쓰지 않으면 수입이 0이다.** 섹터 투자만이 유일한 수입원이며, 타이밍과 포트폴리오 구성이 승부를 가른다.

### 로그라이트 요소

- **런 단위 플레이**: 매 런은 독립적. 30턴 후 승패 판정.
- **시드 기반 RNG**: 동일 시드 → 동일 이벤트/시장 (Mulberry32). 리플레이 가능.
- **메타 진행**: 런 점수의 일부가 메타 화폐로 전환. 영구 업그레이드 구매.
- **런 간 초기화**: 자금, 자산, 영향력, 특성은 매 런 리셋. 메타 업그레이드만 유지.

## 2. 핵심 시스템 요약

| 시스템 | 핵심 |
|--------|------|
| **경제** | 현금 = 행동력. 7섹터 구좌 투자. 소득유형별 차별화 |
| **이벤트** | 매 턴 고정 1개 + 추가 확률. 기회형 50% / 선택형 30% / 압박형 20% |
| **특성** | 시작 시 긍정1+부정1 배정. 이벤트로 추가/제거. 영구 지속. JSON 선언형 |
| **정부** | 매 턴 정부 이벤트 1개. 인플레이션(가격+소득 복리). 정부 탭 |
| **조사** | 정보 구좌 보유 시 사용. 1구좌당 1회/턴. 대상(섹터/경쟁사) 선택 |
| **목표** | 3개 목표 중 1개 선택. 달성 시 순자산에 보너스 가산 |
| **파산** | 현금 마이너스 허용 + 이자 페널티. 매각 자산 없으면 게임오버 |

## 3. 턴 구조

```
  자유 행동        정부           이벤트          정산           결과
┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
│ 무제한    │→│ 정부 이벤트│→│ 일반 이벤트│→│ 경제 계산 │→│ 결과 표시 │→ 다음 턴
│ 매입/매각 │  │ 인플레이션│  │ 특성 부여 │  │ 소득/지출 │  │ 순위 변동 │
│ 섹터 강화 │  │ 정책 선택 │  │ 선택지    │  │ 가치 변동 │  │ 다음 턴   │
│ 조사      │  │ 매 턴 1개│  │ 고정+추가 │  │ 자동 처리 │  │          │
└──────────┘  └──────────┘  └──────────┘  └──────────┘  └──────────┘
 (현금 소진까지)  (필수)         (필수)        (자동)
```

### 3.1 자유 행동 (Free Action)

현금이 허락하는 한 무제한으로 행동한다. AP 개념 없음.

| 행동 | 비용 | 설명 |
|------|------|------|
| **매입** | 섹터 현재가 | 7개 섹터 중 하나에 구좌 매입 (같은 섹터 복수 가능) |
| **매각** | 무료 | 보유 구좌를 현재 시장가로 매각 |
| **섹터 강화** | 강화 비용 | 보유 중인 섹터 전체 구좌의 소득/가치 증가 |
| **조사** | 무료 (정보 구좌 필요) | 정보 섹터 구좌 1개당 1회/턴, 대상 선택 |
| **턴 종료** | - | 즉시 다음 페이즈로 |

### 3.2 정부 (Government)

매 턴 정부 이벤트 1개가 **고정 발생**한다. 인플레이션, 규제, 보조금 등.

- 인플레이션: 자산 가격과 소득이 매 턴 복리로 변동
- 정부 정책에 대한 선택지 제공 (수용/저항/로비 등)
- 정부 탭에서 현재 정책 상태, 인플레이션율, 예고 확인

### 3.3 이벤트 (Event)

매 턴 **고정 1개** + 변동성에 따라 **추가 발생** 가능.

| 유형 | 비율 | 특징 |
|------|------|------|
| 기회형 | 50% | 이득 기회 제공. 행동 시 보상 |
| 선택형 | 30% | 트레이드오프. 선택에 따라 결과 분기 |
| 압박형 | 20% | 손실 회피 상황. 비용 지불로 피해 감소 |

- **특성 부여/제거**: 이벤트 선택에 따라 영구 특성이 부여되거나 제거됨
- **항상 선택권**: 어떤 이벤트든 복수 선택지가 있고 하나를 필수 선택

### 3.4 정산 (Resolution)

시스템이 자동으로 처리:

1. 구좌별 패시브 소득 계산 (소득유형/시장/섹터트렌드/강화/지배력/특성/인플레이션 배율 적용)
2. 이벤트 효과 적용
3. 기본 지출 차감
4. 전 구좌 평가액 갱신 (현재 시장가 기준)
5. 글로벌 시장 상태 업데이트
6. 섹터 트렌드 업데이트
7. 영향력 자연 감소 (-1/턴)
8. **마이너스 잔고 이자** 적용 (파산 페널티)
9. 잔고 갱신, 순위 갱신

### 3.5 결과 (Result)

이번 턴의 소득/지출/순자산 변동/순위 변동을 보여주고, "다음 턴" 클릭.

## 4. 경제 시스템

### 기본 수치

| 항목 | 값 | 설명 |
|------|-----|------|
| 시작 자금 | $3,000 | 메타 업그레이드로 증가 가능 |
| 기본 수익 | $0/턴 | 자산 소득이 유일한 수입원 |
| 기본 지출 | $8/턴 | 생활비. 인플레이션 적용 |
| 시장 풀 | $50,000 | 화폐 보존 법칙의 총 유동성 |
| 시작 영향력 | 0 | 범위: 0~100 |
| AP | 없음 | 현금 = 행동력 |

### 순수익 공식

```
구좌소득  = 소득유형별 계산(섹터프로필, 시장상태, 섹터트렌드)
            × 강화배율 × 지배력배율 × 특성배율 × 인플레이션배율
총수익    = floor(Σ구좌소득 × 이벤트수익배율 × 메타수익배율)
총지출    = floor(기본지출 × 인플레이션배율 × 이벤트지출배율)
순수익    = 총수익 - 총지출 + 이벤트직접금액
잔고      = 잔고 + 순수익
```

### 파산 규칙

| 조건 | 결과 |
|------|------|
| 현금 < 0 | **마이너스 허용** — 매 턴 이자 페널티 발생 |
| 현금 < 0 **이고** 매각 가능 자산 없음 | **파산** — 즉시 런 종료 |
| 턴 30 도달 | **완주** — 정상 런 종료 |

```
이자 페널티 = |마이너스 잔고| × 이자율/턴
```

마이너스 상태에서도 자산이 있으면 매각하여 회복 가능.

## 5. 섹터 투자 시스템

### 7섹터 프로필

각 섹터는 **하나의 투자 대상**이다. 티어 구분 없음. 구좌 단위로 매입/매각한다.

| 섹터 | 기본가 | 소득유형 | 테마 | 설명 |
|------|--------|---------|------|------|
| **외식** 🍔 | $600 | 안정형 | "사람은 먹어야 한다" | 시장 상황 영향 적음. 꾸준한 현금흐름 |
| **기술** 💻 | $1,000 | 시장연동형 | "혁신은 거품과 함께" | 호황 시 고수익, 불황 시 급락 |
| **부동산** 🏢 | $1,200 | 가치연동형 | "땅은 거짓말하지 않는다" | 현재 평가액에 비례한 임대 수익 |
| **물류** 🚛 | $700 | 안정형 | "택배는 멈추지 않는다" | 경기 영향 적음. 외식과 유사하나 더 저렴 |
| **에너지** ⚡ | $900 | 역행형 | "불황에도 전기는 필요하다" | 불황 시 오히려 소득 증가. 헤지 수단 |
| **금융** 💰 | $1,500 | 레버리지형 | "돈이 돈을 번다" | 호황 시 폭발적, 불황 시 큰 손실 |
| **정보** 🔍 | $800 | 특수형 | "정보가 곧 권력" | 소득 낮음. 구좌당 조사 1회/턴 제공 |

### 소득 유형별 공식

| 소득유형 | 공식 | 특성 |
|---------|------|------|
| **안정형** | `고정소득 × 트렌드배율` (시장배율 영향 미미) | 방어적. 변동 적음 |
| **시장연동형** | `평가액 × 수익률 × 시장배율` | 성장주. 호황 시 고수익 |
| **가치연동형** | `평가액 × 수익률` (시장배율 간접 반영) | 자산가치 = 소득 |
| **역행형** | `고정소득 × 역시장배율` (불황↑ 호황↓) | 포트폴리오 헤지 |
| **레버리지형** | `평가액 × 수익률 × 시장배율²` | 극단적 변동 |
| **특수형** | `낮은 고정소득` + 조사 능력 | 소득보다 능력 가치 |

### 가격 변동

```
현재 매입가 = floor(기본가 × 시장배율 × 섹터트렌드배율 × 이벤트보정)
현재 매각가 = floor(현재 평가액 × 매각효율)
현재 평가액 = floor(기본가 × 시장배율 × 섹터트렌드배율)  // 매 턴 갱신
```

- 매입가·매각가·평가액 모두 **매 턴** 시장 상태에 따라 변동
- 정부/이벤트로도 가격 변동 가능
- 매각효율은 시장 상태에 따라 변동 (기존 유지)

### 섹터 강화 (업그레이드 대체)

개별 구좌가 아닌 **섹터 단위** 강화. 해당 섹터의 **모든 보유 구좌**에 효과 적용.

```
강화 비용 = 섹터 기본가 × 0.5 × (현재 강화레벨 + 1)
소득 배율 = 1.2^레벨
최대 레벨 = 3
```

- 해당 섹터에 구좌 1개 이상 보유 시에만 강화 가능
- 강화 효과는 해당 섹터 모든 구좌에 적용
- 섹터 구좌를 전부 매각하면 강화 레벨 유지 (재매입 시 효과 복원)

### 매입/매각

- **매입**: 현재 시장가로 1구좌 매입. 같은 섹터 복수 매입 가능
- **매각**: 보유 구좌 중 선택하여 현재 시장가 기준 매각
- 각 구좌는 개별 추적 (매입가, 매입턴 기록)

## 6. 조사 시스템

### 기본 규칙

- **정보 섹터 구좌 보유가 필수 조건**
- 정보 구좌 1개당 **1회/턴** 조사 가능 (N구좌 = N회/턴)
- 자유 행동 페이즈에서 사용
- 조사 자체는 무료 (정보 구좌 보유가 비용)

### 조사 대상

| 대상 | 얻는 정보 | 전략적 가치 |
|------|----------|------------|
| 섹터 트렌드 | 다음 턴 해당 섹터 방향 | 매입/매각 타이밍 |
| 경쟁사 포트폴리오 | 특정 경쟁사의 보유 구좌 | 지배권 경쟁 판단 |
| 경쟁사 전략 | 전략 타입 공개 | 다음 행동 예측 |
| 시장 전환 | 글로벌 시장 남은 턴 + 전환 방향 | 거시 전략 |

### 정보 섹터의 전략적 가치

- 정보 구좌는 소득이 낮지만 조사 능력이 핵심 자원
- 정보 구좌를 많이 보유할수록 턴당 조사 횟수 증가 → 정보 우위
- 다른 섹터 투자 타이밍을 최적화하는 "메타 섹터"
- 싸게 살 때를 미리 알 수 있다 → 조사가 곧 수익

## 7. 이벤트 시스템

### 기본 규칙

- 매 턴 **고정 1개** + 변동성에 따라 추가 발생
- 모든 이벤트는 **복수 선택지** 제공, 하나 필수 선택
- 이벤트 선택에 따라 **특성 부여/제거**
- 최근 5턴 내 같은 이벤트 반복 없음

### 이벤트 유형 분포

| 유형 | 비율 | 설명 | 예시 |
|------|------|------|------|
| **기회형** | 50% | 이득 기회. 적극 행동 시 보상 | 무역 호황, 파트너십 제안 |
| **선택형** | 30% | 트레이드오프. 전략에 따라 최적 다름 | 기술 혁신, 소비 트렌드 변화 |
| **압박형** | 20% | 피해 최소화. 비용 지불로 손실 감소 | 금융 위기, 세무 조사 |

### 이벤트 효과 타입

| 효과 | 설명 | 지속 |
|------|------|------|
| `money` | 직접 자금 변화 | 즉시 |
| `influence` | 영향력 변화 | 즉시 |
| `trait` | 특성 부여/제거 | 영구 (제거 이벤트까지) |
| `incomeMultiplier` | 소득 배율 | 해당 턴 |
| `expenseMultiplier` | 지출 배율 | 해당 턴 |
| `sectorShift` | 섹터 트렌드 강제 전환 | 다음 전환까지 |
| `marketShift` | 글로벌 시장 강제 전환 | 다음 전환까지 |
| `freeAsset` | 무료 구좌 획득 (섹터 지정) | 즉시 |

## 8. 특성 시스템

### 기본 규칙

- **이벤트로만** 부여/제거 (매입/업그레이드로는 획득 불가)
- **영구 지속** — 제거 이벤트가 발생할 때까지
- **항상 선택권** — 특성 부여/제거 여부를 플레이어가 선택 가능
- **JSON 선언형** — 효과를 데이터로 정의, 로직은 엔진이 해석

### 특성 구조 (JSON)

```json
{
  "id": "market-insider",
  "name": "시장 내부자",
  "description": "금융 자산 소득 +15%",
  "effects": [
    { "type": "incomeMultiplier", "sector": "finance", "value": 1.15 }
  ],
  "source": "partnership-offer",
  "removable_by": ["media-scandal"]
}
```

### 특성 효과 타입

| 효과 | 설명 |
|------|------|
| `incomeMultiplier` | 특정 섹터/전체 소득 배율 |
| `expenseMultiplier` | 지출 배율 |
| `purchaseDiscount` | 매입 할인율 |
| `sellBonus` | 매각 보너스율 |
| `influencePerTurn` | 턴당 영향력 추가 증감 |
| `eventProbability` | 이벤트 발생 확률 보정 |

### 전략적 의미

- 특성은 빌드를 정의: "금융 특화 빌드", "정보 독점 빌드" 등
- 좋은 특성 유지 + 나쁜 특성 회피가 이벤트 선택의 핵심 기준
- 로그라이트 런마다 다른 특성 조합 → 리플레이어빌리티

## 9. 정부 시스템

### 기본 규칙

- **매 턴 정부 이벤트 1개** 고정 발생 (일반 이벤트와 별도)
- 인플레이션은 복리로 누적
- 정부 탭에서 현재 상태 확인

### 인플레이션

```
인플레이션 누적 = (1 + 인플레이션율)^경과턴
자산 가격      = 기본가격 × 인플레이션 누적
소득           = 기본소득 × 인플레이션 누적
지출           = 기본지출 × 인플레이션 누적
```

- 가격과 소득이 함께 오르므로 ROI 비율은 유지
- **지출도 오르므로** 투자하지 않으면 실질적으로 손해가 커짐
- 인플레이션율은 정부 이벤트에 따라 변동

### 정부 이벤트 예시

| 이벤트 | 효과 | 선택지 |
|--------|------|--------|
| 금리 인상 | 인플레이션율 변동 | 대응/수용 |
| 산업 보조금 | 특정 섹터 지원 | 신청/포기 |
| 세금 인상 | 지출 증가 | 절세/수용/로비 |
| 규제 완화 | 특정 섹터 제한 해제 | 진입/관망 |

## 10. 시장 시스템

### 글로벌 시장 상태

섹터별로 시장 배율이 다르게 적용된다 (섹터별 SECTOR_MARKET_MULTIPLIER 참조).

| 상태 | 기본 배율 | 변동성 | 설명 |
|------|----------|--------|------|
| 호황 (boom) | 섹터별 1.1~2.0 | 낮음 | 전반적 수익 증가, 안정적 |
| 보합 (stable) | 섹터별 0.8~1.05 | 보통 | 기본 상태 |
| 불황 (recession) | 섹터별 0.25~0.95 | 높음 | 수익 감소, 이벤트 빈발 |

#### 섹터별 시장 배율 (가격·소득 모두 적용)

| 섹터 | boom | stable | recession | 소득유형 | 특성 |
|------|------|--------|-----------|---------|------|
| 외식 | 1.3 | 1.0 | 0.8 | 안정형 | 가격 변동 적음. 소득에 시장배율 미미 |
| 기술 | 1.7 | 0.9 | 0.4 | 시장연동형 | 가격·소득 모두 시장배율 직접 적용 |
| 부동산 | 1.2 | 1.05 | 0.9 | 가치연동형 | 가격 안정적. 소득은 평가액 비례 |
| 물류 | 1.4 | 1.0 | 0.6 | 안정형 | 외식과 유사. 중간 변동 |
| 에너지 | 1.6 | 1.0 | 0.5 | 역행형 | 가격은 변동, 소득은 불황 시 증가 |
| 금융 | 1.8 | 0.9 | 0.2 | 레버리지형 | 가격·소득 극변동 (시장배율²) |
| 정보 | 1.1 | 1.0 | 0.9 | 특수형 | 초안정. 소득 낮지만 조사 제공 |

### 전환 확률 매트릭스

| 현재 → 다음 | 호황 | 보합 | 불황 |
|-------------|------|------|------|
| **호황** | 20% | 50% | 30% |
| **보합** | 30% | 40% | 30% |
| **불황** | 30% | 50% | 20% |

시장 상태는 4~8턴 유지 후 전환.

### 섹터 트렌드

| 트렌드 | 소득 배율 | 가치 변동 |
|--------|----------|----------|
| 뜨거움 (hot) | ×1.3 | +2%/턴 |
| 중립 (neutral) | ×1.0 | 기본 |
| 침체 (cold) | ×0.7 | -1%/턴 |

- 각 섹터 독립적으로 2~6턴 유지 후 전환
- 글로벌 시장이 섹터 트렌드 전환 확률에 영향

## 11. 지배력 시스템

섹터별 **점유율** (전체 플레이어 대비 내 구좌 비율)로 지배력을 판정한다.

### 판정 기준

```
점유율 = 내 구좌 수 / 전체(모든 기업) 해당 섹터 구좌 수
```

| 조건 | 등급 | 소득 보너스 | 특수 효과 |
|------|------|-----------|----------|
| 구좌 0개 | 미진출 | 없음 | 없음 |
| 구좌 1개 이상 **AND** 점유율 < 30% | 진입자 | 없음 | 없음 |
| 구좌 2개 이상 **AND** 점유율 ≥ 30% | 경쟁자 | +10% | 없음 |
| 구좌 3개 이상 **AND** 점유율 ≥ 50% | 지배자 | +25% | 해당 섹터 이벤트 제3 선택지 해금 |

- **최소 하한값** (구좌 수) + **상대적 점유율** 이중 조건
- 경쟁사가 같은 섹터에 많이 투자하면 지배 난이도 상승
- 조사를 통해 경쟁사 포트폴리오를 파악하고 지배 경쟁 판단

## 13. 승리 조건

### 기본 승리: 순자산 1위

```
순자산 = 현금 + Σ(보유 자산 현재가치)
```

30턴 종료 시 **순자산 1위**가 승리.

### 목표 시스템 (보너스)

런 시작 시 **3개 목표 중 1개**를 선택한다. 달성 시 순자산에 보너스를 가산.

| 목표 예시 | 조건 | 보너스 |
|----------|------|--------|
| 섹터 지배자 | 2개 이상 섹터 지배 | 순자산 +20% |
| 자본 제왕 | 순자산 $30,000 이상 | 순자산 +15% |
| 정보왕 | 정보 섹터 지배 달성 | 순자산 +25% |

목표 미달성 시 보너스 없음 (페널티 없음).
