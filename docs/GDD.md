# WebYouAreCapitalist - 게임 디자인 문서

> 턴제 투자 로그라이트 웹게임. 소액 투자자에서 시작해 30턴 안에 자본가로 성장하라.

---

## 1. 게임 개요

| 항목 | 내용 |
|------|------|
| 장르 | 턴제 투자 로그라이트 |
| 플랫폼 | 웹 (모바일/PC 반응형) |
| 기술 스택 | React 19, TypeScript 5, Zustand 5, Tailwind CSS 3 |
| 1회 플레이 | 30턴 (약 10~15분) |
| 핵심 키워드 | 복리 성장, 리스크/리턴, 섹터 지배, 포트폴리오 최적화 |

### 게임 컨셉

플레이어는 $1,000를 가진 소액 투자자다. 매 턴마다 액션 포인트(AP)를 소모해 자산을 매입하고, 포트폴리오에서 패시브 소득을 얻는다. 시장은 호황과 불황을 오가고, 각 섹터는 독립적으로 뜨거워지거나 식는다. 예상치 못한 이벤트에 대응하며, 같은 섹터에 집중 투자하면 지배력 보너스를 얻는다. 30턴 후 순자산과 영향력으로 최종 점수를 매긴다.

**핵심 메시지: 아무것도 안 사면 수입이 0이다.** 자산만이 유일한 수입원이며, 투자해야 번다.

### 로그라이트 요소

- **런 단위 플레이**: 매 런은 독립적. 30턴 후 점수 산출.
- **시드 기반 RNG**: 동일 시드 → 동일 이벤트/시장 (Mulberry32 알고리즘). 리플레이 가능.
- **메타 진행**: 런에서 번 점수의 일부가 메타 화폐로 전환. 영구 업그레이드 구매.
- **런 간 초기화**: 자금, 자산, 영향력은 매 런 리셋. 메타 업그레이드만 유지.

## 2. 핵심 루프

### 런 구조

```
[새 런 시작] → 턴 1~30 반복 → [런 종료 → 점수 계산 → 메타 화폐 획득]
                                        ↓
                                 [메타 상점에서 업그레이드]
                                        ↓
                                 [다시 새 런 시작...]
```

### 턴 페이즈 (4단계)

```
  Planning          Event            Resolution         Result
┌──────────┐   ┌──────────┐     ┌──────────────┐   ┌──────────┐
│ AP 소진   │──→│ 이벤트    │──→  │ 경제 계산     │──→│ 결과 표시 │──→ 다음 턴
│ 복수 행동 │   │ 선택지 대응│     │ 소득/가치/시장│   │ 다음 턴   │
└──────────┘   └──────────┘     └──────────────┘   └──────────┘
 (AP 0될 때까지)  (40% 확률)         (자동 처리)
```

#### Planning (행동 선택)

플레이어가 AP를 소진할 때까지 복수 행동을 선택한다:

| 행동 | AP 비용 | 설명 |
|------|---------|------|
| **매입** | 1 AP | 15개 자산 중 하나 구매 (비용 차감) |
| **매각** | 1 AP | 보유 자산을 팔아 현금화 |
| **업그레이드** | 1 AP | 보유 자산의 레벨 업 (소득 증가) |
| **시장조사** | 1 AP | 선택한 섹터의 다음 턴 트렌드 확인 |
| **턴 종료** | 0 AP | 남은 AP를 버리고 즉시 다음 페이즈로 |

#### Event (이벤트 대응)

40%+α 확률로 이벤트 발생. 기본 2개 선택지 중 1개 선택 필수.
해당 섹터 지배자일 경우 제3 선택지 활성화.
이벤트가 없으면 이 단계를 건너뛴다.

#### Resolution (경제 계산)

시스템이 자동으로 처리:
1. 자산별 패시브 소득 계산 (시장/섹터/업그레이드/지배력 배율 적용)
2. 이벤트 효과 적용
3. 기본 지출 차감
4. 자산 가치 업데이트 (appreciation)
5. 글로벌 시장 상태 업데이트
6. 섹터 트렌드 업데이트
7. 영향력 자연 감소 (-1/턴)
8. 잔고 갱신

#### Result (결과 확인)

이번 턴의 소득/지출/순자산 변동 내역을 보여주고, 플레이어가 "다음 턴" 클릭.

### 게임오버 조건

| 조건 | 결과 |
|------|------|
| 현금 < 0 **이고** 매각 가능 자산 없음 | **파산** — 즉시 런 종료 |
| 턴 30 도달 | **완주** — 정상 런 종료 |

현금이 마이너스여도 매각 가능한 자산이 있으면 게임은 계속된다 (자산 처분 유예).

## 3. 경제 시스템

### 기본 수치

| 항목 | 값 | 설명 |
|------|-----|------|
| 시작 자금 | $1,000 | 메타 업그레이드로 최대 +$1,000 |
| 기본 수익 | $0/턴 | 자산 소득이 유일한 수입원 |
| 기본 지출 | $15/턴 | 생활비, 유지비 |
| 시작 영향력 | 0 | 범위: 0~100 |
| 기본 AP | 2/턴 | 메타 업그레이드로 최대 3 |

### 순수익 공식

```
자산소득  = Σ(자산.baseIncome × 업그레이드배율 × 시장배율 × 섹터트렌드배율 × 지배력배율)
총수익    = floor(자산소득 × 이벤트수익배율 × 메타수익배율)
총지출    = floor(기본지출 × 이벤트지출배율)
순수익    = 총수익 - 총지출 + 이벤트직접금액
잔고      = 잔고 + 순수익
```

### 영향력 (Influence)

- 범위: 0~100, 시작 0
- 획득:
  - 자산 매입: Tier 1 +2, Tier 2 +3, Tier 3 +5
  - 이벤트 선택에 따라 증감
  - 섹터 지배 달성 시 +10
- 자연 감소: -1/턴
- 0~100으로 클램핑

#### 영향력 티어별 효과

| 영향력 구간 | 효과 |
|------------|------|
| 0~19 | 없음 |
| 20~39 | 자산 매입 비용 5% 할인 |
| 40~59 | 시장조사 AP 비용 0 (무료) |
| 60~79 | 이벤트 긍정 효과 20% 증가 |
| 80~100 | 모든 자산 소득 +10% |

## 4. 자산 시스템

### 5섹터 × 3티어 = 15개 자산

| 섹터 | Tier 1 (진입) | Tier 2 (성장) | Tier 3 (지배) |
|------|--------------|--------------|--------------|
| **외식** | 포장마차 $100 | 레스토랑 $400 | 프랜차이즈 $1,200 |
| **기술** | 앱 스타트업 $150 | SaaS 기업 $500 | 테크 대기업 $1,500 |
| **부동산** | 원룸 임대 $200 | 상가 건물 $600 | 오피스 타워 $2,000 |
| **유통** | 편의점 $120 | 마트 체인 $450 | 대형 유통사 $1,300 |
| **금융** | P2P 대출 $180 | 투자 펀드 $550 | 은행 지분 $1,800 |

### 자산 수익 구조

각 자산은 두 가지 방식으로 수익을 생성한다:

#### 패시브 소득 (매 턴)

```
턴 소득 = baseIncome × 업그레이드배율 × 시장배율 × 섹터트렌드배율 × 지배력배율
```

- **baseIncome**: 자산별 고정 기본 소득 (매 턴 자동 발생)
- 배율은 시장 상태, 섹터 트렌드, 업그레이드 레벨, 지배력 등급에 따라 변동

#### 자산 가치 변동 (appreciation)

```
현재가치 = 매입가 × (1 + appreciation_rate)^보유턴수
```

- **appreciation_rate**: 섹터/시장에 따라 양수(상승) 또는 음수(하락)
- 매각 시 현재 가치 기준으로 매각 금액 결정 → 차익/차손 발생

### 업그레이드

보유 중인 자산에 추가 투자하여 소득을 높인다.

```
업그레이드 비용 = 자산원가 × 0.3 × (현재레벨 + 1)
소득 증가     = +25% / 레벨
최대 레벨     = 3
```

| 업그레이드 레벨 | 소득 배율 | 비용 (원가 $100 기준) |
|---------------|----------|---------------------|
| 0 (기본) | ×1.0 | - |
| 1 | ×1.25 | $30 |
| 2 | ×1.50 | $60 |
| 3 | ×1.75 | $90 |

### 매각

보유 자산을 팔아 현금화할 수 있다.

```
매각금액 = floor(현재가치 × 매각효율)
```

- 매각효율은 시장 상태에 따라 변동 (호황 시 유리, 불황 시 불리)
- 업그레이드 비용은 매각 시 반환되지 않음

### 투자 전략

| 전략 | 특징 | 적합한 상황 |
|------|------|-----------|
| 분산 투자 | 여러 섹터에 소액 분산 | 안정적, 지배력 보너스 없음 |
| 섹터 집중 | 한 섹터에 3개 올인 | 지배력 +25%, 섹터 침체 시 위험 |
| 티어 업 | 저가 매입 → 업그레이드 | 장기 소득 극대화 |
| 시세 차익 | hot 섹터 매입 → 가치 상승 후 매각 | 단기 차익, 타이밍 중요 |

## 5. 액션 포인트 (AP) 시스템

### 기본 규칙

- 매 턴 시작 시 AP 회복 (기본 2, 메타 업그레이드로 최대 3)
- Planning 페이즈에서 AP가 0이 되거나 턴 종료를 선택할 때까지 행동 반복
- 미사용 AP는 다음 턴으로 이월되지 않음

### 행동 상세

| 행동 | AP | 효과 | 비고 |
|------|-----|------|------|
| 매입 | 1 | 자산 구매, 포트폴리오에 추가 | 현금 부족 시 불가 |
| 매각 | 1 | 보유 자산 판매, 현금 획득 | 보유 자산 없으면 불가 |
| 업그레이드 | 1 | 보유 자산 레벨 +1 | 최대 레벨 3, 비용 필요 |
| 시장조사 | 1 | 선택 섹터의 다음 턴 트렌드 확인 | 영향력 40+ 시 AP 0 |
| 턴 종료 | 0 | 남은 AP 포기, 다음 페이즈 진행 | 언제든 가능 |

## 6. 시장 시스템

### 글로벌 시장 상태

| 상태 | 소득 배율 | 변동성 범위 | 설명 |
|------|----------|------------|------|
| 호황 (boom) | ×1.3 | 0.2~0.5 (낮음) | 전반적 수익 증가, 안정적 |
| 보합 (stable) | ×1.0 | 0.3~0.7 (보통) | 기본 상태 |
| 불황 (recession) | ×0.7 | 0.5~0.9 (높음) | 수익 감소, 이벤트 빈발 |

### 글로벌 시장 전환

시장은 4~8턴 동안 유지된 후 다음 상태로 전환된다.

**전환 확률 매트릭스:**

| 현재 → 다음 | 호황 | 보합 | 불황 |
|-------------|------|------|------|
| **호황** | 20% | 50% | 30% |
| **보합** | 30% | 40% | 30% |
| **불황** | 30% | 50% | 20% |

### 섹터 트렌드

각 섹터는 글로벌 시장과 별개로 독립적인 트렌드를 가진다.

| 트렌드 | 소득 배율 | 가치 변동 | 설명 |
|--------|----------|----------|------|
| 뜨거움 (hot) | ×1.3 | +2%/턴 추가 | 인기 섹터, 고수익 |
| 중립 (neutral) | ×1.0 | 기본 | 평상시 |
| 침체 (cold) | ×0.7 | -1%/턴 감소 | 비인기 섹터, 저수익 |

#### 섹터 트렌드 전환

- 매 턴 각 섹터의 트렌드가 독립적으로 전환 가능
- 글로벌 시장 상태가 섹터 트렌드 전환 확률에 영향:
  - 호황 시 → hot으로 전환 확률 증가
  - 불황 시 → cold로 전환 확률 증가

### 변동성 (Volatility)

시장의 변동성은 이벤트 발생 확률에 직접 영향을 준다.

```
이벤트 발생 확률 = 40% + 변동성 × 30%
```

- 불황 시 변동성 높음 → 이벤트 많이 발생 → 리스크 증가
- 호황 시 변동성 낮음 → 안정적 플레이 가능

## 7. 지배력 (Dominance) 시스템

같은 섹터에 자산을 집중하면 지배력 등급이 올라가며 보너스를 얻는다.

### 지배력 등급

| 같은 섹터 자산 수 | 등급 | 소득 보너스 | 특수 효과 |
|-----------------|------|-----------|----------|
| 1개 | 진입자 | 없음 | 없음 |
| 2개 | 경쟁자 | +10% | 없음 |
| 3개 | 지배자 | +25% | 해당 섹터 이벤트에서 제3 선택지 해금 |

### 지배력 전략

- **진입자**: 탐색 단계. 섹터 트렌드를 확인하며 투자 결정.
- **경쟁자**: 소득 +10%로 안정적 수익 확보. 3번째 자산 매입 여부 판단.
- **지배자**: 소득 +25% + 제3 선택지로 이벤트에서 독점적 이득. 해당 섹터 집중 리스크와 트레이드오프.

## 8. 이벤트 시스템

### 기본 규칙

- 매 턴 40%+α 확률로 이벤트 발생
- 기본 2개 선택지 제공 (하나 필수 선택)
- 해당 섹터 지배자일 경우 제3 선택지 활성화
- 최근 5턴 내 같은 이벤트 반복 없음
- 가중치 기반 랜덤 선택 (weight가 높을수록 자주 등장)

### 이벤트 목록 (12개)

#### 경제 이벤트 (4개)

| # | 이름 | 최소 턴 | 가중치 | 선택지 A | 선택지 B |
|---|------|--------|--------|---------|---------|
| 1 | 금리 인상 | 3 | 10 | 안전자산 이동: 금융 섹터 소득 +20%, 기술 섹터 소득 -10% | 현상 유지: 효과 없음 |
| 2 | 경기 부양책 | 5 | 8 | 적극 투자: 다음 매입 비용 -20% | 관망: 전체 소득 ×1.1 (1턴) |
| 3 | 금융 위기 | 10 | 5 | 공매도: -$200, 다음 턴 소득 ×1.5 | 방어: 전 자산 가치 -5%, 소득 유지 |
| 4 | 무역 호황 | 6 | 7 | 수출 확대: 유통 섹터 hot 전환 | 내수 집중: 외식 섹터 소득 +15% |

#### 섹터 이벤트 (3개)

| # | 이름 | 최소 턴 | 가중치 | 선택지 A | 선택지 B | 지배자 선택지 C |
|---|------|--------|--------|---------|---------|--------------|

## 9. 메타 진행 시스템

### 메타 화폐

런이 끝나면 점수의 1%가 메타 화폐로 전환된다 (최소 1).

```
메타 화폐 = max(1, floor(점수 × 0.01))
```

### 메타 업그레이드 (7개)

| 이름 | 효과 | 최대 레벨 | 기본 비용 | 레벨별 비용 |
|------|------|----------|----------|------------|
| 시드 캐피탈 | 시작 자금 +$200/레벨 | 5 | 5 | 5, 10, 15, 20, 25 |
| 시간 관리 | 최대 턴 +2/레벨 | 3 | 8 | 8, 16, 24 |
| 투자 안목 | 자산 소득 ×(1 + 0.1×레벨) | 5 | 10 | 10, 20, 30, 40, 50 |
| 협상력 | 자산 매입 비용 -10%/레벨 | 3 | 7 | 7, 14, 21 |
| 위기 감각 | 나쁜 이벤트 리롤 +15%/레벨 | 2 | 12 | 12, 24 |
| 멀티태스킹 | AP +1 | 1 | 20 | 20 |
| 인맥 | 시작 영향력 +15/레벨 | 3 | 8 | 8, 16, 24 |

### 비용 공식

```
실제 비용 = 기본비용 × (현재레벨 + 1)
```

레벨 0→1: 기본비용 × 1, 레벨 1→2: 기본비용 × 2, ...

### 업그레이드 효과 상세

- **시드 캐피탈 Lv5**: 시작 자금 $1,000 → $2,000
- **시간 관리 Lv3**: 최대 턴 30 → 36
- **투자 안목 Lv5**: 자산 소득 ×1.5
- **협상력 Lv3**: 자산 매입 비용 30% 할인
- **위기 감각 Lv2**: 30% 확률로 나쁜 이벤트 리롤
- **멀티태스킹 Lv1**: AP 2 → 3/턴
- **인맥 Lv3**: 시작 영향력 0 → 45

## 10. 점수 시스템

### 점수 공식

```
순자산     = 현금 + Σ(보유 자산 현재가치)
점수       = 순자산 × 1 + 영향력 × 20 + 턴 수 × 5 + 지배 섹터 수 × 500
```

| 요소 | 가중치 | 예시 |
|------|--------|------|
| 순자산 | ×1 | $10,000 → 10,000점 |
| 영향력 | ×20 | 60 → 1,200점 |
| 생존 턴 | ×5 | 30턴 → 150점 |
| 지배 섹터 | ×500 | 2개 → 1,000점 |

### 점수 예시

- **파산 (턴 12)**: $0 × 1 + 10 × 20 + 12 × 5 + 0 × 500 = **260점**
- **평범한 완주**: $5,000 × 1 + 30 × 20 + 30 × 5 + 0 × 500 = **5,750점**
- **좋은 완주**: $20,000 × 1 + 60 × 20 + 30 × 5 + 1 × 500 = **22,350점**
- **완벽한 런**: $80,000 × 1 + 90 × 20 + 30 × 5 + 3 × 500 = **83,450점**

### 경제 스케일

$1,000 시작 → 좋은 런 $50,000~$100,000 / 완벽한 런 $200,000+
