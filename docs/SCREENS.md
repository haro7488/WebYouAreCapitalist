# 화면 설계서

> 4개 화면의 와이어프레임, 사용 컴포넌트, 동작 명세.
> 기존 컴포넌트 참조: `src/components/common/`, `src/components/game/`

---

## 화면 전환 흐름도

```
                    ┌──────────┐
                    │ MainMenu │
                    └────┬─────┘
                ┌────────┴────────┐
                ▼                 ▼
          ┌──────────┐     ┌──────────┐
          │   Game   │     │ MetaShop │
          └────┬─────┘     └──────────┘
               │                 ▲
               ▼                 │
          ┌──────────┐           │
          │RunResult │───────────┘
          └──────────┘
               │
               ▼
          (MainMenu 또는 다시 Game)
```

```
┌──────────────────────────────────┐
│                                  │
│                                  │
│      WebYouAreCapitalist         │

│                                  │
│      ┌────────────────────┐      │
│      │    새 게임 시작     │      │  ← Button (primary, lg)
│      └────────────────────┘      │
│                                  │
│      ┌────────────────────┐      │
│      │     메타 상점       │      │  ← Button (secondary, lg)
│      └────────────────────┘      │
│                                  │

│      총 플레이: 12회              │  ← metaStore.totalRunsPlayed
```

### 동작

| 요소 | 클릭 시 |
|------|--------|

### 사용 컴포넌트

- `Button` (primary/secondary, lg, fullWidth)

### 데이터 소스

- `useMetaStore`: `metaState.bestScore`, `metaState.totalRunsPlayed`, `metaState.currency`

## Game (게임 플레이)

게임 화면은 `gameState.phase`에 따라 다른 컨텐츠를 보여준다.
GameHeader는 모든 페이즈에서 항상 표시.

### Planning 페이즈

```
┌──────────────────────────────────┐
│ [GameHeader]                     │  ← sticky top
│  턴 5/30  ⭐ 80  💰 $1,234 📈 호황 │
├──────────────────────────────────┤
│                                  │
│  (기본 뷰: 간단한 상태 요약)       │
│  또는                            │
│  [InvestmentList] - 투자 목록     │  ← "투자" 탭 선택 시
│  또는                            │
│  [Portfolio] - 보유 투자          │  ← "매각" 탭 선택 시
│                                  │
├──────────────────────────────────┤
│ [ActionBar]                      │  ← fixed bottom
│  [투자]    [매각]    [스킵]       │
└──────────────────────────────────┘
```

**동작 흐름:**
1. 화면 진입 시 기본 뷰 (간단한 잔고/평판 요약)
2. "투자" 클릭 → InvestmentList 표시 (6개 투자 카드 그리드)
3. "매각" 클릭 → Portfolio 표시 (보유 투자 목록)
4. "스킵" 클릭 → `submitAction({ type: 'skip' })` → 다음 페이즈
5. 투자 구매/매각 시 → `submitAction(...)` → 다음 페이즈

### Event 페이즈

```
┌──────────────────────────────────┐
│ [GameHeader]                     │
├──────────────────────────────────┤
│                                  │
│  [EventCard]                     │
│  ┌──────────────────────────┐    │
│  │ ⚡ 위생 점검              │    │
│  │                          │    │
│  │ 갑작스러운 위생 점검이     │    │
│  │ 예정되었습니다.            │    │
│  │                          │    │
│  │ ┌──────────────────────┐ │    │
│  │ │ 청소에 투자 -$80 ⭐+5 │ │    │
│  │ └──────────────────────┘ │    │
│  │ ┌──────────────────────┐ │    │
│  │ │ 그냥 검사   ⭐-10    │ │    │
│  │ └──────────────────────┘ │    │
│  └──────────────────────────┘    │
│                                  │
└──────────────────────────────────┘
```

**동작:** 선택지 클릭 → `submitEventChoice(choiceId)` → Resolution

### Resolution 페이즈

자동 처리 단계. `resolvePhase()` 호출 후 즉시 Result로 전환.
(향후 애니메이션 추가 가능)

### Result 페이즈

```
┌──────────────────────────────────┐
│ [GameHeader]                     │
├──────────────────────────────────┤
│                                  │
│  [TurnResult]                    │
│  ┌──────────────────────────┐    │
│  │ 📊 턴 5 결과             │    │
│  │                          │    │
│  │ ↗️ 기본 수익     $50     │    │
│  │ ↗️ 투자 수익     $24     │    │
│  │ ↙️ 지출         -$30     │    │
│  │ ──────────────────────── │    │
│  │ 💰 순수익        $44     │    │
│  │ 💳 잔고        $1,044    │    │
│  │                          │    │
│  │ 📈 시장: 호황             │    │
│  │                          │    │
│  │     [ 다음 턴 ]          │    │
│  └──────────────────────────┘    │
│                                  │
└──────────────────────────────────┘
```

**동작:**
- "다음 턴" → `advanceTurn()` → Planning으로 돌아감
- 게임오버 시 → "결과 보기" 버튼 → `endCurrentRun()` → RunResult 화면

### 사용 컴포넌트

| 페이즈 | 컴포넌트 |
|--------|---------|
| 공통 | GameHeader |
| Planning | ActionBar, InvestmentList, Portfolio |
| Event | EventCard |
| Result | TurnResult |

### 데이터 소스

- `useGameStore`: `gameState` (전체), `submitAction`, `submitEventChoice`, `resolvePhase`, `advanceTurn`, `endCurrentRun`

```
┌──────────────────────────────────┐
│                                  │

│    (파산 / 30턴 완주)             │  ← gameOverReason
│                                  │
│  ┌──────────────────────────┐    │
│  │ 📊 최종 결과             │    │
│  │                          │    │
│  │ 💰 최종 자금    $2,500   │    │
│  │ 🏆 총 턴        30      │    │
│  │ ⭐ 최종 점수    3,250    │    │
│  │ ──────────────────────── │    │
│  │ 🪙 획득 메타 화폐  32    │    │
│  └──────────────────────────┘    │
│                                  │
│  ┌──────────────────────────┐    │
│  │ 💼 최종 포트폴리오        │    │
│  │ 정기 예금     $100       │    │
│  │ 인덱스 펀드   $300       │    │
│  └──────────────────────────┘    │
│                                  │
│      ┌──────────────────┐        │
│      │    다시 하기      │        │  ← Button (primary)
│      └──────────────────┘        │
│      ┌──────────────────┐        │
```

### 동작

| 요소 | 클릭 시 |
|------|--------|
| 다시 하기 | `gameStore.startRun()` → `uiStore.navigateTo('game')` |
| 메인으로 | `uiStore.navigateTo('mainMenu')` |

### 사용 컴포넌트

- `Card`, `StatRow`, `MoneyDisplay`, `Button`

### 데이터 소스

- `useGameStore`: `lastRunResult` (finalMoney, totalTurns, score, metaCurrencyEarned, investments)

## MetaShop (메타 상점)

영구 업그레이드를 구매하는 화면.

### 와이어프레임

```
┌──────────────────────────────────┐
│  ← 뒤로     메타 상점            │  ← 헤더
│             🪙 42                │  ← 메타 화폐 잔고
├──────────────────────────────────┤
│                                  │
│  ┌──────────────────────────┐    │
│  │ 시드 머니          Lv 2/5│    │
│  │ 시작 자금 +$200/레벨      │    │
│  │ 현재: +$400              │    │
│  │                          │    │
│  │ 다음 레벨 비용: 🪙 15     │    │
│  │      [ 업그레이드 ]       │    │
│  └──────────────────────────┘    │
│                                  │
│  ┌──────────────────────────┐    │
│  │ 추가 시간          Lv 0/3│    │
│  │ 최대 턴 +2/레벨           │    │
│  │ 현재: 없음               │    │
│  │                          │    │
│  │ 다음 레벨 비용: 🪙 8      │    │
│  │      [ 업그레이드 ]       │    │
│  └──────────────────────────┘    │
│                                  │
│  ... (5개 업그레이드 카드)        │
│                                  │
└──────────────────────────────────┘
```

### 동작

| 요소 | 클릭 시 |
|------|--------|
| 뒤로 | `uiStore.goBack()` |
| 업그레이드 | `metaStore.purchaseUpgrade(upgradeId)` |

### 업그레이드 카드 상태

| 상태 | 표시 |
|------|------|
| 구매 가능 | 버튼 활성 (primary) |
| 화폐 부족 | 버튼 비활성, "화폐 부족" 표시 |
| 최대 레벨 | 버튼 숨김, "최대 레벨" 뱃지 표시 |

### 사용 컴포넌트

- `Card`, `Button`, `Badge`, `ProgressBar` (레벨 게이지)

### 데이터 소스

- `useMetaStore`: `metaState.currency`, `metaState.upgrades`, `purchaseUpgrade()`
- `@game/index`: `META_UPGRADES` (업그레이드 정의)
